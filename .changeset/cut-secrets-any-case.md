A secret cut short by an observation limit is redacted in any case, not only as typed. An editor under CSS `text-transform: uppercase` echoing a filled credential after filler showed the upper-cased cut value in the model input, `failure/screen.txt`, and the report, since the cut match and the trace's fragment scrub compared the value exactly while whole-value matching already ignored case. Both now compare case-folded, as whole values do; a case mapping that changes length (`ß` as `SS`) is still not followed there.
