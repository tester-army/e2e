The built-in agent can try an upload when the step names no file. `upload` takes `sample:photo.png`, `sample:photo.jpg`, `sample:document.pdf`, `sample:notes.txt`, `sample:table.csv`, and `sample:empty.txt`, small files e2e ships, and the tool lists them. An `e2e mcp` upload of a sample prints no test line, since a test needs a project file.
