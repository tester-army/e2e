`defineConfig` is an identity function for type checking and editor completion.
Every rule below is enforced when the runner resolves the config, not when
`defineConfig` is called.

```ts
export function defineConfig(config: E2EConfig): E2EConfig;
```

```ts title="e2e.config.ts"
import { defineConfig } from 'e2e';
import { playwright } from '@e2edev/playwright';

export default defineConfig({
  app: { url: process.env.APP_URL ?? 'http://localhost:3000' },
  targets: [{ name: 'web', platform: 'web', backend: playwright({ browser: 'chromium' }) }],
});
```

Unknown keys are rejected with `INVALID_CONFIG` at every level: top level, `app`,
`agent`, `agent.model`, and `limits`.

## Loading

`--config <path>` selects an explicit file. Otherwise the runner searches the
working directory and each parent for `e2e.config.ts` or `e2e.config.mts`,
stopping at the repository root. Both names in one directory is
`CONFIG_AMBIGUOUS`. The selected file's directory is the project root; with no
config file, the working directory is.

A config file is required: the runner ships no backend, so `targets` must name
the one that drives each target. `npx e2e init` writes a starter config.

## Top level

| Key | Type | Default | Valid range |
| --- | --- | --- | --- |
| `projectId` | `string` | nearest `package.json` name, else a generated ID | 1-256 characters |
| `app` | `AppConfig` | see [app](#app) | - |
| `targets` | `readonly Target[]` | required | non-empty |
| `tests` | `string \| readonly string[]` | `'tests/**/*.e2e.ts'` | non-empty, `/` separators, duplicates removed |
| `timeout` | `number` | `120000` | positive safe integer |
| `launchTimeout` | `number` | `60000` | positive safe integer |
| `actionTimeout` | `number` | `30000` | positive safe integer; bounds every backend operation, including each observation and action inside an agent step |
| `assertionTimeout` | `number` | `5000` | positive safe integer |
| `cleanupTimeout` | `number` | `30000` | positive safe integer |
| `retries` | `number` | `1` in CI, else `0` | integer 0-10 |
| `workers` | `number` | `1` in CI, else `max(1, floor(availableParallelism() / 2))` | integer 1-1024 |
| `artifacts` | `readonly ('trace' \| 'screenshot')[]` | `['screenshot', 'trace']` | those two kinds |
| `reporters` | `readonly ('list' \| 'json')[]` | `['list']` | those two IDs; `json` cannot be combined with `list` |
| `screen` | object | see [screen](#screen) | - |
| `agent` | object | see [agent](#agent) | - |
| `cache` | string or object | `'read-write'` (`'read-only'` in CI) | see [cache](#cache) |
| `limits` | object | see [limits](#limits) | - |
| `credentials` | record | `{}` | see [credentials](#credentials) |

Every numeric value must be a safe integer.

`artifacts` accepts `screenshot` and `trace` only; `video` is not a
configurable artifact kind. A configured kind the target's backend cannot
produce fails before collection with `UNSUPPORTED_ARTIFACT`.
Every run writes `.e2e/report.json` regardless of the selected reporters.

## app

```ts
export interface AppConfig {
  url?: string;
  command?: CommandConfig;
  readyUrl?: string;
  allowedOrigins?: readonly string[];
  environment?: 'test' | 'staging' | 'production';
  allowProduction?: boolean;
  identity?: string;
}
```

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `url` | `string` | `APP_URL` | One of the two is required, else `APP_URL_REQUIRED`. No userinfo, query, or fragment; HTTP only for loopback. |
| `command` | `CommandConfig` | unset | Structured app process, never shell-interpreted |
| `readyUrl` | `string` | the resolved base URL | Readiness probe; a status of 200-499 counts as ready |
| `allowedOrigins` | `readonly string[]` | the origin of `url` | Each entry must be a serialized origin |
| `environment` | `'test' \| 'staging' \| 'production'` | `'test'` for loopback, `.localhost`, and `.test` hosts, otherwise required | Any other host without an explicit value is `ENVIRONMENT_REQUIRED` |
| `allowProduction` | `boolean` | `false` | `environment: 'production'` without it is `PRODUCTION_NOT_ALLOWED` |
| `identity` | `string` | derived from the base URL's origin | Stable logical app identity for cache/session keying. Set it when the origin is ephemeral (a per-PR preview URL) so entries survive redeploys; never share one identity across genuinely different apps. The environment always joins the derived identity. |

### app.command

```ts
export interface CommandConfig {
  executable: string;
  args?: readonly string[];
  cwd?: string;
  env?: Readonly<Record<string, string>>;
  startupTimeout?: number;
  shutdownTimeout?: number;
}
```

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `executable` | `string` | - | Required, non-empty, resolved with the process `PATH` |
| `args` | `readonly string[]` | `[]` | Passed verbatim |
| `cwd` | `string` | project root | Resolved from the project root |
| `env` | `Record<string, string>` | `{}` | Adds to the inherited set |
| `startupTimeout` | `number` | `60000` | Ready-probe budget; expiry is `APP_UNREACHABLE` |
| `shutdownTimeout` | `number` | `10000` | Grace period before force-kill |

The child inherits only `PATH`, `HOME`, `TMPDIR`, `TMP`, `TEMP`, `SystemRoot`,
and `COMSPEC` when present, plus `app.command.env`. Model credentials,
`E2E_USER_*` values, and CI tokens are never inherited. The runner never
terminates a process it did not start.

## targets

Target names are required, unique, and limited to ASCII letters, digits, `_`,
`-`, and `.`. An empty `targets` array is an error.

```ts
export interface Target {
  name: string;
  platform: Platform;
  backend?: BackendHandle; // defineBackend(...) from 'e2e/backend'
}
```

Every target is served by a backend, and the runner knows only the backend
contract: the backend's declared capabilities (observation, actions, location,
state, artifacts, contributed fixtures) grade what the target serves, and
anything undeclared fails loud with `UNSUPPORTED_CAPABILITY`. A target without
a `backend` is agent-tools-only and runs everything opaque. `app.url` is
optional until a test calls `app.open()`. With an `executor` in the `agent`
block, a custom brain composes with the model, budget, and context options
instead of replacing them.

| Key | Type | Default | Notes |
| --- | --- | --- | --- |
| `name` | `string` | - | Stable ID used by `--target`, reports, sessions, and artifact paths |
| `platform` | `Platform` | - | Any label; `platforms: [...]` on a test filters against it |
| `backend` | `BackendHandle` | none | `playwright({ browser?, viewport?, connect? })` from `@e2edev/playwright` for a browser (`connect` attaches to a remote browser over CDP); `agentDevice({ platform, app? })` from `@e2edev/agent-device` for an [iOS or Android device](/reference/device); any [`defineBackend`](/writing-a-backend) handle otherwise |

Browser choice and viewport are options of the playwright backend, not of the
runner:

```ts
targets: [
  { name: 'chromium', platform: 'web', backend: playwright() },
  { name: 'webkit-mobile', platform: 'web', backend: playwright({ browser: 'webkit', viewport: { width: 390, height: 844 } }) },
],
```

## agent

```ts
agent?: {
  model?: string | ModelConfig | ModelInstance;
  visionModel?: string | ModelConfig | ModelInstance;
  maxSteps?: number;
  maxModelCalls?: number;
  maxObservationBytes?: number;
  context?: string;
  vision?: boolean | 'fallback' | 'only';
};
```

| Key | Type | Default | Valid range | Notes |
| --- | --- | --- | --- | --- |
| `model` | `string \| ModelConfig \| ModelInstance` | unset | - | No implicit default. Unset means acquiring `agent` fails with `MODEL_UNAVAILABLE`. |
| `visionModel` | `string \| ModelConfig \| ModelInstance` | `agent.model` | - | Model used by calls with `vision`. Same three forms as `model`. Built on first vision call. |
| `maxSteps` | `number` | `25` | integer 1-100 | Committed actions per agent call |
| `maxModelCalls` | `number` | `25` | integer 1-100 | Model requests per agent call |
| `maxObservationBytes` | `number` | `1048576` | integer 1024-16777216 | Observation payload ceiling. Not a `limits` key. |
| `context` | `string` | unset | at most `limits.maxAgentContextBytes` UTF-8 bytes | Trusted project context prepended to agent prompts. Exceeding the budget is `INVALID_CONFIG`. |
| `vision` | `boolean \| 'fallback' \| 'only'` | `false` | - | Project-wide default for the per-call `vision` option. `'fallback'` behaves like `false` for `assert`, `waitFor`, and `extract`; `'only'` sends pixels instead of the tree. A per-call value wins. |

### agent.model

```ts
export interface ModelConfig {
  provider: string;
  id: string;
  endpoint?: string;
  /** Environment variable containing the provider credential. */
  apiKeyEnv?: string;
}

export interface ModelInstance {
  readonly specificationVersion: string;
  readonly provider: string;
  readonly modelId: string;
}
```

| Form | Example | Behavior |
| --- | --- | --- |
| String | `'openai/gpt-4o'` | Split at the first `/` and routed through the AI Gateway. A leading or trailing `/` is `INVALID_CONFIG`. |
| `ModelConfig` | `{ provider: 'openai', id: 'gpt-4o' }` | `provider` and `id` are required and non-empty |
| `ModelInstance` | `openai('gpt-4o')` | Any AI SDK model instance. Detected structurally; owns its own transport and credentials. |

| `ModelConfig` key | Default | Rules |
| --- | --- | --- |
| `endpoint` | gateway default | Must be HTTPS unless the host is loopback |
| `apiKeyEnv` | `'E2E_MODEL_API_KEY'` | Must match `/^[A-Za-z_][A-Za-z0-9_]*$/` |

Each worker re-resolves the config module and constructs its own model instance,
so an instance never crosses a process boundary. A config whose digest differs
between the runner and a worker fails with `CONFIG_NOT_DETERMINISTIC`.

## credentials

```ts
credentials?: Readonly<
  Record<
    string,
    {
      username: string;
      password: string | SecretProvider;
      allowedOrigins?: readonly string[];
    }
  >
>;

type SecretProvider = () => string | Promise<string>;
```

| Key | Type | Required | Notes |
| --- | --- | --- | --- |
| `username` | `string` | yes | Default username |
| `password` | `string \| SecretProvider` | yes | A static value, or a provider called on every authorized fill — a vault lookup, a freshly computed TOTP. Recorded in the config digest by name only; a resolved value joins redaction the moment it exists and never reaches a model. An `E2E_USER_*` env override wins over a provider. |
| `allowedOrigins` | `readonly string[]` | no | Narrows this credential relative to `app.allowedOrigins`. It can only narrow. |

`credentials.user(name)` resolves a configured entry into a `Credential`. The
username is a plain string; the password is an opaque `Secret` that test code
cannot read, accepted only by `locator.fill` and `agent.act` params.

```ts
export interface Secret {
  readonly name: string;
  readonly purpose: 'password' | 'one-time-code' | 'generic-secret';
  readonly [secretBrand]: true;
}

export interface Credential {
  readonly name: string;
  readonly username: string;
  readonly password: Secret;
  readonly [credentialBrand]: true;
}
```

An unconfigured name, or a call outside an active runner, throws
`AUTH_CREDENTIAL_UNAVAILABLE` with exit code 2.

```ts title="e2e.config.ts"
export default defineConfig({
  app: { url: 'http://localhost:3000' },
  credentials: {
    member: { username: 'member@example.test', password: 'local-dev-only' },
    admin: {
      username: 'admin@example.test',
      password: 'local-dev-only',
      allowedOrigins: ['http://localhost:3000'],
    },
  },
});
```

## cache

The adaptive trace cache: each passing `agent.act()` step records the grammar
actions it performed, and the next run replays them zero-turn — diverging to
the live agent mid-step whenever the app no longer matches the recording.
Judgments (`assert`, `waitFor`, `extract`) are never cached.

The cache is **on by default** (`read-write`; CI is forced to `read-only`).
Opt out per project with `cache: 'off'`, or per run with `e2e run --no-cache`
— the quickest way to check whether a failure is cache-related.

| Key | Type | Default | Description |
| --- | --- | ---: | --- |
| `mode` | `'off' \| 'read-only' \| 'read-write'` | `'read-write'` | A bare string is shorthand for `{ mode }`. CI forces `read-write` on the default file store down to `read-only`; `--no-cache` wins over both. |
| `store` | `TraceCacheStore` | file store | Custom entry store (for example a shared remote cache). Exempt from the CI clamp — it is not a committed file cache, and states its own trust through `writable`. Never crosses a process boundary; workers re-resolve the config module. |
| `dir` | `string` | `.e2e/cache` | File store directory, resolved against the project root. |

Entries are disposable: deleting `.e2e/cache/` slows the next run and changes
nothing else. Every agent step's report records how the cache participated
(`step.cache`: `self-finalized`, `agent-concluded`, or `missed`, with a
reason).

## limits

Resolved limits are immutable for a run. Per-call options may only lower them.

Every limit is enforced: a key exists here exactly when the runner has an
enforcement site for it, so a configured limit is never a silent no-op.

| Key | Type | Default | Range | Description |
| --- | --- | ---: | --- | --- |
| `maxAgentContextBytes` | `number` | `16384` | 1024-65536 | Trusted agent context |
| `maxLedgerBytes` | `number` | `8192` | 1024-65536 | Prior-step ledger |
| `maxEventsPerStep` | `number` | `1000` | 1-10000 | Events recorded per step |
| `maxModelTokensPerCall` | `number` | `64000` | 1-1000000 | Tokens per model request |

## Environment variables

The runner reads a closed set. There are no verbosity variables; diagnostics are
`e2e run --debug` and `e2e run --ai-trace`.

| Variable | Effect |
| --- | --- |
| `APP_URL` | Base URL fallback when `app.url` is unset |
| `E2E_MODEL` | `provider/model-id` fallback when `agent.model` is unset |
| `E2E_VISION_MODEL` | `provider/model-id` fallback when `agent.visionModel` is unset |
| `E2E_MODEL_API_KEY` | Default provider credential |
| `AI_GATEWAY_API_KEY` | Gateway credential, used when the named key variable holds no value |
| `E2E_USER_<NAME>_USERNAME` | Overrides `credentials.<name>.username` |
| `E2E_USER_<NAME>_PASSWORD` | Overrides `credentials.<name>.password` |
| `CI` | Switches CI defaults and rejects focused tests |

### Resolution order

| Setting | Order |
| --- | --- |
| Base URL | `app.url`, then `APP_URL`, then `APP_URL_REQUIRED` |
| Model | `agent.model`, then `E2E_MODEL` parsed as `provider/model-id`, then `MODEL_UNAVAILABLE` at `agent` acquisition |
| Vision model | `agent.visionModel`, then `E2E_VISION_MODEL`, then `agent.model` |
| Model credential | the variable named by `agent.model.apiKeyEnv`, else `E2E_MODEL_API_KEY`, then `AI_GATEWAY_API_KEY` |
| Credential username and password | the `E2E_USER_*` variable, then the config value |

"First non-empty" ignores values that are undefined or whitespace only. Naming
`apiKeyEnv` replaces the default variable name rather than adding to it. A
missing model credential is not a config error; it surfaces as
`MODEL_UNAVAILABLE` when the `agent` fixture is acquired.

An `E2E_USER_*` pair for a name that is not in the `credentials` block is
ignored. The variable name is the credential name uppercased with every character
outside `A-Z0-9` replaced by `_`, so `power-user` becomes
`E2E_USER_POWER_USER_USERNAME` and `E2E_USER_POWER_USER_PASSWORD`.

### CI

CI mode is on unless `CI` is unset, empty, whitespace only, `0`, or `false`. The
value is trimmed and lowercased first, so `FALSE` is also falsy. Every other
value, including `no` and `off`, turns CI mode on.

| Setting | Local | CI |
| --- | --- | --- |
| `retries` | `0` | `1` |
| `workers` | `max(1, floor(availableParallelism() / 2))` | `1` |
| `test.only` | allowed | `ONLY_IN_CI`, exit code 2 |
