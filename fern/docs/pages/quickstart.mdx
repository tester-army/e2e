subtitle: Install, define your agent, run a test.

<Callout intent="note">
Requires Node.js 20.19 or newer.
</Callout>

<Steps>
  <Step title="Install">
    <CodeBlocks>
      ```bash title="npm"
      npm install --save-dev @e2edev/e2e @e2edev/playwright ai
      ```
      ```bash title="pnpm"
      pnpm add -D @e2edev/e2e @e2edev/playwright ai
      ```
    </CodeBlocks>

    `e2e` is the runner and SDK. `@e2edev/playwright` is the browser backend:
    the runner itself knows no platform, so every target names the backend
    that drives it. `ai` is the AI SDK the built-in agent runs on; it is an
    optional peer, so a suite without agents can skip it.
  </Step>

  <Step title="Define your agent">
    ```bash
    npx --no-install e2e init
    ```

    ```ts title="e2e.config.ts"
    import { defineConfig } from '@e2edev/e2e';
    import { playwright } from '@e2edev/playwright';

    export default defineConfig({
      app: { url: 'localhost:3000' },
      targets: [{ name: 'web', platform: 'web', backend: playwright() }],
    });
    ```

    Point `app.url` at your app. A scheme is optional: `localhost:3000`
    becomes `http://localhost:3000` and `app.example.com` becomes
    `https://app.example.com`. The runner knows no platform, so every target
    names the backend that drives it.

    Without an `agent` key the runner uses the built-in tool-loop agent. To
    shape it, construct one and pass it:

    ```ts title="e2e.config.ts"
    import { createAgent } from '@e2edev/e2e/agent';

    export default defineConfig({
      // ...
      agent: createAgent({
        system: 'You are a thorough QA agent. Verify every outcome on screen.',
      }),
    });
    ```

    `system` shapes how it works. Later you can hand it your own tools, or
    replace it with a custom executor; [Your own agent](/agents) covers both.

    The model comes from the `E2E_MODEL` environment variable as a
    `provider/model-id` string, routed through the Vercel AI Gateway so one
    `E2E_MODEL_API_KEY` reaches any provider. To use a provider directly, pass
    an AI SDK model instance: `createAgent({ model: openai('gpt-5.4-mini') })`.

    The runner can also start your dev server: set `app.command`.
  </Step>

  <Step title="Write a test">
    Test files match `tests/**/*.e2e.ts`.

    ```ts title="tests/signup.e2e.ts"
    import { test } from '@e2edev/playwright';
    import { expect } from '@e2edev/e2e';

    test('a visitor signs up for a trial', async ({ app, agent, screen }) => {
      await app.open('/');

      await agent.act('sign up for a free trial as {name} with email {email}', {
        name: 'Ada Lovelace',
        email: 'ada@example.test',
      });

      await agent.assert('the welcome screen greets Ada by name');
      await expect(screen.getByRole('status')).toContainText('trial');
    });
    ```

    Import `test` from `@e2edev/playwright` when a test touches the `web`
    fixture: it is the same runtime `test` as `e2e`'s, typed with the fixture
    the browser backend contributes. One goal per `act`. Real values go through
    `params`, not through the instruction. The final `expect` is deterministic: it costs no model calls
    and cannot vary. There are no waits or sleeps anywhere: queries poll,
    actions wait, assertions retry.
  </Step>

  <Step title="Run">
    ```bash
    E2E_MODEL=anthropic/claude-sonnet-4.5 E2E_MODEL_API_KEY=... npx --no-install e2e run
    ```

    Missing browsers download automatically on the first run.

    ```bash
    npx --no-install e2e run tests/signup.e2e.ts   # one file
    npx --no-install e2e run --tag smoke           # by tag
    npx --no-install e2e run --headed              # watch it happen
    npx --no-install e2e run --debug               # save full agent transcripts
    npx --no-install e2e run --ai-trace            # record every model call for a trace viewer
    ```

    Every run writes `.e2e/report.json`: results, attempts, steps, artifacts,
    and model usage. Exit codes separate test failures (1) from configuration
    (2) and infrastructure (3); blocked agent steps land in the latter two.
  </Step>
</Steps>
