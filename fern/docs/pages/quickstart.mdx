<Callout intent="note">
Requires Node.js 20.19 or newer.
</Callout>

<Steps>
  <Step title="Install">
    <CodeBlocks>
      ```bash title="npm"
      npm install --save-dev e2e @e2edev/playwright ai
      ```
      ```bash title="pnpm"
      pnpm add -D e2e @e2edev/playwright ai
      ```
    </CodeBlocks>

    `e2e` is the runner and SDK, `@e2edev/playwright` is the default web
    driver, and `ai` (the AI SDK) powers the built-in agent. Skip `ai` for a
    purely deterministic suite — it is an optional peer.
  </Step>

  <Step title="Scaffold and point at your app">
    ```bash
    npx e2e init
    ```

    ```ts title="e2e.config.ts"
    import { defineConfig } from 'e2e';

    export default defineConfig({
      app: { url: process.env.APP_URL ?? 'http://localhost:3000' },
      agent: { model: 'anthropic/claude-sonnet-4.5' },
    });
    ```

    The model is a `provider/model-id` string routed through the Vercel AI
    Gateway — one `E2E_MODEL_API_KEY` reaches any provider — or a live AI SDK
    model instance with its own credentials. `E2E_MODEL` overrides it per run.
    The runner can also start your dev server: give `app.command` an
    executable and args.
  </Step>

  <Step title="Write a test">
    Test files match `tests/**/*.e2e.ts`.

    ```ts title="tests/signup.e2e.ts"
    import { test, expect } from 'e2e';

    test('a visitor signs up for a trial', async ({ app, agent, screen }) => {
      await app.open('/');

      await agent.act('sign up for a free trial as {name} with email {email}', {
        name: 'Ada Lovelace',
        email: 'ada@example.test',
      });

      await agent.assert('the welcome screen greets Ada by name');
      await expect(screen.getByRole('status')).toContainText('trial');
    });
    ```

    One goal per `act`, real values through `params`, and a deterministic
    `expect` on the outcome you must not let drift. No waits, no sleeps —
    queries poll, actions wait, assertions retry.
  </Step>

  <Step title="Run">
    ```bash
    E2E_MODEL_API_KEY=... npx e2e run
    ```

    Missing browsers download automatically on the first run.

    ```bash
    npx e2e run tests/signup.e2e.ts   # one file
    npx e2e run --tag smoke           # by tag
    npx e2e run --headed              # watch it happen
    npx e2e run --debug               # save full agent transcripts
    ```

    Every run writes `.e2e/report.json` — results, attempts, steps, artifacts,
    and model usage — whether it passed, failed, or was interrupted. Exit codes
    separate test failures (1) from configuration (2) and infrastructure (3),
    and blocked agent steps land in the latter two, not in red.
  </Step>
</Steps>
