The `app` fixture opens, restarts, and resets the app under test, and takes
screenshots. It is on every target. A method the engine can't perform fails
with `UNSUPPORTED_CAPABILITY`.

```ts title="tests/billing.e2e.ts"
import { expect, test } from 'e2e';

test('billing page', async ({ app, screen }) => {
  await app.open('/settings/billing');
  await expect(screen.getByRole('heading', { name: 'Billing' })).toBeVisible();
  await app.screenshot('billing');
});
```

## Reference

| Member | Returns |
| --- | --- |
| [`baseUrl`](#baseurl) | `string \| undefined` |
| [`open`](#open) | `Promise<void>` |
| [`restart`](#restart) | `Promise<void>` |
| [`clearState`](#clearstate) | `Promise<void>` |
| [`back`](#back) | `Promise<void>` |
| [`screenshot`](#screenshot) | `Promise<string>` |

`open`, `restart`, and `clearState` are bounded by `timeout`. `back` and
`screenshot` are bounded by `actionTimeout`. Both come from the
[config](/reference/config): `timeout` defaults to 120000 ms and
`actionTimeout` to 30000 ms. The remaining test timeout caps both. `app`
methods take no per-call timeout option.

### `baseUrl`

The resolved base URL of the target's app.

```ts
const health = await fetch(`${app.baseUrl}/api/health`);
```

- When `app.url` declares port `0`, `baseUrl` carries the port the run
  allocated.
- On a target that declares no `app.url`, it is `undefined`.

### `open`

Opens the app: the declared URL, a path relative to it, or any absolute
`http(s)` URL.

```ts
await app.open(); // the target's app.url
await app.open('/settings/billing'); // a path relative to app.url
await app.open('https://example.com/login'); // any http(s) URL
```

On a device target, which has no URL, `open()` launches the pinned app fresh
and takes no path.

| Throws | When |
| --- | --- |
| `APP_URL_REQUIRED` | A path, on a target that declares no `app.url`. |
| `POLICY_DENIED` | A URL whose scheme is not `http:` or `https:`. `about:blank` is allowed. |
| `APP_UNREACHABLE` | The app URL could not be reached. |
| `ACTION_FAILED` | The operation failed or timed out. |
| `UNSUPPORTED_CAPABILITY` | No `session.open` on a target with a URL, or no `session.restart` on one without. |

### `restart`

Recreates the execution context and keeps persisted state. Then it reopens
the app at its base URL when the target declares one.

```ts
await app.restart();
```

| Throws | When |
| --- | --- |
| `ACTION_FAILED`, `ENGINE_FAILURE` | The operation or the engine failed. |
| `UNSUPPORTED_CAPABILITY` | No `session.restart`. |

### `clearState`

Clears persisted client state and recreates the execution context. Then it
reopens the app at its base URL when the target declares one.

```ts
test.beforeEach(async ({ app }) => {
  await app.clearState();
});
```

| Throws | When |
| --- | --- |
| `ACTION_FAILED`, `ENGINE_FAILURE` | The operation or the engine failed. |
| `UNSUPPORTED_CAPABILITY` | No `session.reset`. |

<Warning>
`clearState` inside a serial group destroys the shared state the group
depends on. Use it in `beforeEach` of an ordinary group instead.
</Warning>

### `back`

Navigates back once.

```ts
await app.back();
```

| Throws | When |
| --- | --- |
| `APP_NOT_OPEN` | `app.open()` has not run, or the engine reported invalid state. |
| `ACTION_FAILED` | The operation failed or timed out. |
| `UNSUPPORTED_CAPABILITY` | No `session.back`. |

### `screenshot`

Captures a redacted evidence screenshot and returns its path.

```ts
const shot = await app.screenshot('after-checkout');
```

- The file is an attempt artifact under `screenshots/`. The returned path is
  absolute. The report records the path relative to the artifact root.
- `label` names the step and joins the file name.

| Throws | When |
| --- | --- |
| `UNSUPPORTED_CAPABILITY` | The engine takes no screenshots. |
| `ENGINE_FAILURE` | The capture failed. |

<Note>
The screenshot masks secure fields only, after a `Secret` fill too. A secret
the app shows anywhere else is in the image. See
[screenshots after a secret fill](/reference/security#screenshots-after-a-secret-fill).
</Note>

## Types

```ts
export interface App {
  /**
   * The resolved base URL of the target's app, with the port the run
   * allocated when `app.url` declared port 0; undefined for a target that
   * declares no `app.url`.
   */
  readonly baseUrl: string | undefined;
  /**
   * Opens the app: the declared URL, a path relative to it, or any absolute
   * http(s) URL. On a device target, which has no URL, it launches the pinned
   * app fresh and takes no path.
   */
  open(path?: string): Promise<void>;
  /**
   * Recreates the execution context while preserving persisted state, then
   * reopens the app at its base URL when the target declares one.
   */
  restart(): Promise<void>;
  /**
   * Clears persisted client state, recreates the execution context, then
   * reopens the app at its base URL when the target declares one.
   */
  clearState(): Promise<void>;
  /** Navigates back once. */
  back(): Promise<void>;
  /** Captures a redacted evidence screenshot and returns its absolute path. */
  screenshot(label?: string): Promise<string>;
}
```
