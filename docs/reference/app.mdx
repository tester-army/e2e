---
title: app
description: The portable app lifecycle fixture, available on every platform.
---

Every `app` method exists on every platform. The engine implements each; the
runner owns the timeouts.

```ts
export interface App {
  readonly baseUrl: string | undefined;
  open(path?: string): Promise<void>;
  restart(): Promise<void>;
  clearState(): Promise<void>;
  back(): Promise<void>;
  screenshot(label?: string): Promise<string>;
}
```

`baseUrl` is the URL `open()` resolves paths against, with the port the run
allocated when the URL was declared with port `0` (see
[free ports](/reference/config#free-ports)). It is `undefined` on a target
whose engine declares no `url`.

No `App` method takes a `timeout` option. Each budget is additionally capped
by the remaining test timeout.

| Method | Timeout | Behavior | Throws |
| --- | --- | --- | --- |
| `open(path?)` | `config.timeout`, 120000 ms | Opens the base URL, or an absolute URL or path relative to it. | `APP_URL_REQUIRED` when the engine declares no `url`, `POLICY_DENIED` for a `file:`, `data:`, or `javascript:` URL, `APP_UNREACHABLE`, `ACTION_FAILED`, `UNSUPPORTED_CAPABILITY` without `session.open` |
| `restart()` | `config.timeout`, 120000 ms | Recreates the context, keeps persisted state including a restored session, and reopens the app when the target has a URL. | `ACTION_FAILED`, `ENGINE_FAILURE`, `UNSUPPORTED_CAPABILITY` without `session.restart` |
| `clearState()` | `config.timeout`, 120000 ms | Clears cookies, storage, and other persisted state, discards a restored session, then reopens the app. | `ACTION_FAILED`, `ENGINE_FAILURE`, `UNSUPPORTED_CAPABILITY` without `session.reset` |
| `back()` | `config.actionTimeout`, 30000 ms | Navigates back once. | `APP_NOT_OPEN`, `ACTION_FAILED`, `UNSUPPORTED_CAPABILITY` without `session.back` |
| `screenshot(label?)` | `config.actionTimeout`, 30000 ms | Captures a screenshot as an attempt artifact and returns its path relative to the artifact root. `label` names the step and joins the file name. | `POLICY_DENIED` after a secret fill, `UNSUPPORTED_CAPABILITY`, `ENGINE_FAILURE` |

```ts
await app.open('/settings/billing');
const shot = await app.screenshot('after-checkout');
```

<Warning>
`clearState` inside a serial group destroys the shared state the group
depends on. Use it in `beforeEach` of an ordinary group instead.
</Warning>

Once a `Secret` has been filled, pixels are withheld for the rest of the
session, including later tests in a serial group. `app.screenshot()` then
fails with `POLICY_DENIED` and creates no artifact.

Browser-only operations live on the [`web`](/reference/playwright) fixture;
device operations on [`device`](/reference/agent-device).
