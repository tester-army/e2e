Every runner error carries a class and a code. The class sets the exit code,
and the code names the cause. A model never selects either. `e2e login`,
`e2e logout`, and `e2e models` are the exception, under
[Exit codes](#exit-codes).

```ts title="tests/upgrade.e2e.ts"
import { isAgentError, test } from 'e2e';

test('upgrade to Pro', async ({ agent }) => {
  try {
    await agent.act('upgrade the workspace to Pro');
  } catch (error) {
    if (isAgentError(error) && error.code === 'STEP_TIMEOUT') {
      // the step ran out of time; the message carries the last judgment
      console.error(error.category, error.details);
    }
    throw error;
  }
});
```

## Reference

### Exit codes

| Class | Exit code |
| --- | ---: |
| test | 1 |
| configuration | 2 |
| infrastructure | 3 |
| internal | 4 |
| interrupted | 130 |

- In a mixed run the highest-precedence code present wins,
  `130 > 4 > 3 > 2 > 1 > 0`. The report keeps every individual result.
- A setup assertion failure is a test failure and skips its dependents.
  Missing setup infrastructure keeps its configuration or infrastructure
  class.
- The `internal` class and exit code 4 are reserved for runner invariant
  violations. No first-party code raises a code in that class today.
- `e2e login`, `e2e logout`, and `e2e models` print a failure's message with
  no code and exit 1, or 130 when a sign-in or picker is cancelled.

| Codes | Description |
| --- | --- |
| [Agent codes](#agent-codes) | The `code` of an `AgentError` |
| [Runner codes](#runner-codes) | Plain strings in output and report |
| [Test code errors](#test-code-errors) | Thrown from test code |

### AgentError

`AgentError` is the runner-classified agent failure, exported from `e2e`.

```ts
/** Runner-classified agent failure. */
export class AgentError extends Error {
  /** Closed union, assigned by the runner, never taken from model text. */
  readonly code: AgentErrorCode;
  /** The error class in the table above; it sets the exit code. */
  readonly category: 'test' | 'configuration' | 'infrastructure' | 'internal' | 'interrupted';
  readonly retryable: boolean;
  /** Structured facts: locator, expected, observed, match count, wait time. */
  readonly details: ErrorDetails | undefined;
  /** Sanitized, bounded prose; the same value as `message`. */
  readonly explanation: string;
  /** Artifact path, present only when evidence was captured and permitted. */
  readonly screenshot?: string;
  /** True when this failure reports a blocked step, not a product failure. */
  readonly blocked: boolean;
}
```

<Note>
Test files load in their own module realm, so `instanceof AgentError` can be
false. Use `isAgentError` from `e2e` and branch on `code`, as in the example
at the top of this page.
</Note>
