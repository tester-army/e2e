## Port the config

<Note>Set up a target with the [mobile guide](/mobile) and a model with the [quickstart](/quickstart). Both runners can use the same simulator while you move one spec at a time.</Note>

| Detox (`.detoxrc.js`) | e2e |
| --- | --- |
| `apps.<name>.binaryPath`, `bundleId` | `app: { appPath, bundleId }` on the target |
| `devices.<name>.device.type` | `mobile({ device: 'iPhone 17' })` |
| `configurations` | `targets`, one engine per platform |
| Jest `maxWorkers` | `workers`, one per device |
| `apps.<name>.launchArgs` | `app.launchArguments` on the target, a list of strings for each platform |
| `launchApp({ permissions })` | `app.permissions` on the target: `grant`, `deny`, `reset` for `YES`, `NO`, `unset`. More names are [planned](#planned) |

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';

export default {
  targets: [
    {
      name: 'ios',
      engine: mobile({ platform: 'ios' }),
      app: { bundleId: 'com.example.app', appPath: 'ios/build/MyApp.app' },
    },
    {
      name: 'android',
      engine: mobile({ platform: 'android' }),
      app: { bundleId: 'com.example.app', appPath: 'android/app/build/outputs/apk/debug/app-debug.apk' },
    },
  ],
  workers: 1,
} satisfies E2EConfig;
```

## Rewrite one spec

Nothing launches on its own, so the e2e test starts with `app.open()`. The
password comes from [configured credentials](/authentication).

```js title="Detox"
describe('login', () => {
  beforeAll(async () => { await device.launchApp({ newInstance: true }); });

  it('shows the home screen', async () => {
    await element(by.id('email')).typeText('ada@example.test');
    await element(by.id('password')).typeText('hunter2');
    await element(by.text('Sign in')).tap();
    await waitFor(element(by.id('home'))).toBeVisible().withTimeout(10000);
    await expect(element(by.text('Welcome, Ada'))).toBeVisible();
  });
});
```

```ts title="e2e"
import { test } from '@e2e-dev/mobile';
import { expect, credentials } from 'e2e';

test('shows the home screen', async ({ agent, app, screen }) => {
  await app.open();
  const ada = credentials.user('ada');
  await agent.act('sign in as {username}', { params: { username: ada.username, password: ada.password } });
  await expect(screen.getByTestId('home')).toBeVisible({ timeout: 10_000 });
  await expect(screen.getByText('Welcome, Ada')).toBeVisible();
});
```

## Map each Detox call

### Matchers and actions

| Detox | e2e |
| --- | --- |
| `by.id('x')`, `by.text('t')`, `by.label('l')` | `screen.getByTestId('x')`, `screen.getByText('t')`, `screen.getByLabel('l')` |
| `by.id('x').withAncestor(by.id('row'))` | `screen.getByTestId('row').getByTestId('x')` |
| `.atIndex(n)` | `.nth(n)` |
| `.tap()`, `.tap({ x, y })`, `.longPress()`, `.multiTap(2)` | `.tap()`, `.tap({ position: { x, y } })`, `.longPress()`, `.doubleTap()` |
| `.typeText(t)` | `.pressSequentially(t)` |
| `.replaceText(t)`, `.clearText()`, `.tapReturnKey()` | `.fill(t)`, `.clear()`, `.press('Enter')` |
| `.swipe('up', 'fast')` | `.swipe({ direction: 'down', momentum: 'fast' })`. Detox names the finger's direction, e2e the content's |
| `list.scroll(200, 'down')` | `list.swipe({ direction: 'down' })`, with no offset |
| `waitFor(el).toBeVisible().whileElement(list).scroll(...)` | `list.scrollUntilVisible(el)`, with `{ direction: 'up' }` when Detox scrolls up |

### Expectations

| Detox | e2e |
| --- | --- |
| `waitFor(el).toBeVisible().withTimeout(ms)` | `await expect(el).toBeVisible({ timeout: ms })` |
| `.toBeVisible()`, `.toHaveText(t)` | The same |
| `.not.toBeVisible()` | `.toBeHidden()` |
| `.toExist()`, `.not.toExist()` | `.toBeAttached()`, `.toBeAttached({ attached: false })` |
| `.toHaveToggleValue(true)` | `.toBeChecked()` |
| `.toHaveLabel(l)` | `.toHaveAccessibleName(l)` |
| `.toHaveValue(v)` | `.toHaveValue(v)`, on a form control only |

### Device

| Detox | e2e |
| --- | --- |
| `device.launchApp({ newInstance: true })` | `app.restart()` |
| `device.launchApp({ newInstance: false })` | `device.openApp(id)` without `relaunch` |
| `device.launchApp({ launchArgs, permissions })` | `device.openApp(id, { relaunch: true, launchArguments, permissions })` |
| `device.resetAppState()` | `app.clearState()` |
| `device.launchApp({ delete: true })` | `device.installApp(path, { reinstall: true })`, then `app.open()` |
| `device.launchApp({ url })`, `device.openURL({ url })` | `device.openLink(url)` |
| `device.terminateApp()`, `sendToHome()`, `pressBack()` | `device.closeApp()`, `home()`, `back()` |
| `device.setLocation(lat, lon)`, `setOrientation('landscape')` | `device.setLocation({ latitude, longitude })`, `setOrientation('landscape-left')` |
| `device.setBiometricEnrollment(true)` | `device.enrollBiometrics('faceid', true)` |
| `device.matchFace()`, `unmatchFace()`, `matchFinger()`, `unmatchFinger()` | `device.setBiometrics('faceid' \| 'touchid', 'match' \| 'nonmatch')` |
| `device.takeScreenshot()` | `app.screenshot('label')`, or [`toHaveScreenshot`](/visual-testing) to compare |
| `device.getPlatform()` | The `platform` fixture |
| `:ios:` / `:android:` in a test name | `{ platforms: ['ios'] }` on the test |

## What e2e doesn't have yet

Planned is on the roadmap, and Not yet has no date. Not planned is left out
on purpose.

### Planned

| Detox | Use today |
| --- | --- |
| `beforeAll` that launches the app | `app.open()` in `beforeEach` |
| Install at init, `behavior.init.reinstallApp`, `--reuse` | `device.installApp()` in a fixture |
| `artifacts.plugins.log`, `--record-logs` | `adb logcat` or `xcrun simctl spawn booted log stream` in a CI step |
| `by.id('x').and(by.text('y'))` | `.filter({ hasText })`, or `device.locator('id=x label="y"')` |
| `system.element(by.system.label('Allow'))` | `device.alert('accept' \| 'dismiss')`, or `app.permissions` so no prompt shows |
| `.longPressAndDrag()`, `.swipe()` offset, `.multiTap(3)` | `.dragTo(target)`, `screen.swipe({ from, to })`, repeated `.tap()` |
| `.scrollTo('bottom')` | `list.scrollUntilVisible(lastRow)`, or the first row with `{ direction: 'up' }` |
| `.tapBackspaceKey()` | `.fill(t)` with the shorter text |
| `.setDatePickerDate()`, `.setColumnToValue()`, `.adjustSliderToPosition()` | An `agent.act` goal, or `screen.swipe({ from, to })` on a slider |
| `.toHaveValue(v)` outside a form control | `expect(device.locator('id=x value="v"')).toBeVisible()` |
| `permissions` for `health`, `homekit`, `speech`, `faceid`, `userTracking`; values `always`, `inuse`, `limited` | Tap the prompt's button, or `device.alert('accept')` |
| `device.sendUserNotification()`, `device.uninstallApp()`, `.pinch()` | `client.apps.push()`, `client.apps.uninstall()`, `client.interactions.pinch()` on [`unstable_raw`](/reference/mobile#unstable_raw) |
| `launchApp({ languageAndLocale })` | On iOS, `app.launchArguments: ['-AppleLanguages', '(fr)', '-AppleLocale', 'fr_FR']`, see [Run the app in another language](/mobile#run-the-app-in-another-language) |
| Jest `globalSetup`, `globalTeardown` | Start dependencies before the run |
| `device: { type, os }`, `headless`, `bootArgs`, `device.reverseTcpPort()` | Create and boot the device, and run `adb reverse`, in a CI step |
| `device.shake()` | - |

### Not yet

| Detox | Use today |
| --- | --- |
| `apps.<name>.build`, `detox build` | Your normal build, before `e2e run` |
| `launchArgs` as one key-value map | `['-key', 'value']` on iOS, `['--es', 'key', 'value']` on Android |
| `.scroll()` by an exact offset | `screen.swipe({ from, to })` |
| `by.type('RCTImageView')` | `device.locator('role=image')`, or a `testID` |
| `.getAttributes()` | `.textContent()`, `.inputValue()`, `.isEnabled()`, `.isVisible()`, `.isChecked()`, `.boundingBox()` |
| `.toBeVisible(50)`, and the 75% default | `.toBeVisible()` checks the platform's flag, not the area. Compare `.boundingBox()` |
| `web.element(by.web.cssSelector('x'))` | The WebView's accessibility text and labels, or an `agent.act` goal |
| Jest reporters, Allure | The `junit` reporter, or a custom reporter |
| `device.resetContentAndSettings()` | `app.clearState()`, plus `device.clearKeychain()` on iOS |
| `device.setStatusBar()` | `xcrun simctl status_bar`. `toHaveScreenshot` holds the status bar fixed |

### Not planned

| Detox | Use instead |
| --- | --- |
| `device.reloadReactNative()` | `app.restart()`. A reload needs the Detox framework in the app |
| `device.disableSynchronization()`, `enableSynchronization()` | Delete the calls. There is no synchronization to switch off |
| `device.setURLBlacklist()` | Delete the call. Network activity never blocks an action |

## What differs on purpose

- e2e doesn't wait for the app to be idle. Actions wait and assertions retry.
  For a control that is still arriving, raise [`transition`](/reference/mobile#transition);
  for agent actions, [`settle`](/reference/mobile#settle).
- The engine installs nothing on its own. Call `device.installApp()`.
- [Locators](/reference/screen) are strict. An action on several matches fails
  with `LOCATOR_AMBIGUOUS`. Narrow with `.filter()`, `.first()`, or `.nth()`.
- A device has no `test.setup` or `{ session }`. See
  [what differs from the web](/mobile#what-differs-from-the-web).
