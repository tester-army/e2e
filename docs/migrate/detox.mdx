`@e2e-dev/mobile` drives a simulator or emulator using your normal debug
or release build. It does not need the Detox framework. React Native
`testID` props work with `getByTestId` on both platforms.

Set up a target with the [mobile guide](/mobile) and a model with the
[quickstart](/quickstart). You can use the same simulator for each runner
while migrating one spec at a time.

## Config

| Detox (`.detoxrc.js`) | e2e |
| --- | --- |
| `apps.<name>.binaryPath` | `app: { appPath }` on the target plus one `device.installApp()` per device in a fixture; the engine installs nothing on its own |
| `apps.<name>.bundleId` | `app: { bundleId: 'com.example.app' }` on the target, the app `app.open()` launches |
| `devices.<name>.device.type` | `mobile({ device: 'iPhone 17' })` |
| `configurations` | `targets`, one engine per platform |
| Jest config, `maxWorkers` | `workers`, one per device |
| `detox build` | Your normal build. No Detox framework, no `detox build` step |
| `device.launchApp({ permissions })` | `app.permissions` on the target, set before every fresh launch, or `device.openApp(app, { relaunch: true, permissions })` for one; `grant`, `deny`, `reset` for `YES`, `NO`, `unset` |
| `device.launchApp({ launchArgs })` | `app.launchArguments` on the target, or `device.openApp(app, { relaunch: true, launchArguments })` for one; a list of strings the platform launch command takes, not a map |

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { mobile } from '@e2e-dev/mobile';

export default {
  targets: [
    {
      name: 'ios',
      engine: mobile({ platform: 'ios' }),
      app: { bundleId: 'com.example.app', appPath: 'ios/build/MyApp.app' },
    },
    {
      name: 'android',
      engine: mobile({ platform: 'android' }),
      app: { bundleId: 'com.example.app', appPath: 'android/app/build/outputs/apk/debug/app-debug.apk' },
    },
  ],
  workers: 1,
} satisfies E2EConfig;
```

## A test, before and after

```js title="Detox"
describe('login', () => {
  beforeAll(async () => { await device.launchApp({ newInstance: true }); });

  it('shows the home screen', async () => {
    await element(by.id('email')).typeText('ada@example.test');
    await element(by.id('password')).typeText('hunter2');
    await element(by.text('Sign in')).tap();
    await waitFor(element(by.id('home'))).toBeVisible().withTimeout(10000);
    await expect(element(by.text('Welcome, Ada'))).toBeVisible();
  });
});
```

```ts title="e2e"
import { test } from '@e2e-dev/mobile';
import { expect, credentials } from 'e2e';

test('shows the home screen', async ({ agent, app, screen }) => {
  await app.open();
  const ada = credentials.user('ada');
  await agent.act('sign in as {username}', { params: { username: ada.username, password: ada.password } });
  await expect(screen.getByTestId('home')).toBeVisible({ timeout: 10_000 });
  await expect(screen.getByText('Welcome, Ada')).toBeVisible();
});
```

`app.open()` launches the configured app fresh; nothing launches on its own.
The password comes from [configured credentials](/authentication).

## API map

| Detox | e2e |
| --- | --- |
| `by.id('x')` | `screen.getByTestId('x')` |
| `by.text('t')` | `screen.getByText('t')` |
| `by.label('l')` | `screen.getByLabel('l')` |
| `by.type('RCTImageView')` | `device.locator('role=Image')`, agent-device's selector syntax |
| `by.id('x').withAncestor(by.id('row'))` | `screen.getByTestId('row').getByTestId('x')` |
| `.atIndex(n)` | `.nth(n)` |
| `.tap()`, `.multiTap(2)`, `.longPress()` | `.tap()`, `.doubleTap()`, `.longPress()` |
| `.tap({ x, y })` | `.tap({ position: { x, y } })` |
| `.typeText(t)`, `.replaceText(t)` | `.fill(t)` replaces the content |
| `.clearText()` | `.clear()` |
| `.tapReturnKey()` | `.press('Enter')` |
| `.swipe('up', 'fast')` | `.swipe({ direction: 'down', momentum: 'fast' })`: Detox names the finger's direction, e2e the content's |
| `.scroll(200, 'down')` | `screen.swipe({ direction: 'down' })` |
| `waitFor(el).toBeVisible().whileElement(list).scroll(...)` | `screen.scrollUntilVisible(el)` |
| `waitFor(el).toBeVisible().withTimeout(ms)` | `await expect(el).toBeVisible({ timeout: ms })` |
| `expect(el).toBeVisible()`, `.toExist()` | `.toBeVisible()` for visibility; `.toHaveCount(1)` for existence |
| `expect(el).not.toBeVisible()` | `.toBeHidden()` |
| `expect(el).toHaveText(t)` | `.toHaveText(t)` |
| `expect(el).toHaveToggleValue(true)` | `.toBeChecked()` |
| `expect(el).toHaveValue(v)` | `.toHaveValue(v)` |
| `device.launchApp({ newInstance: true })` | `app.restart()` |
| `device.launchApp({ delete: true })` | `app.clearState()` |
| `device.reloadReactNative()` | No equivalent. `app.restart()` is the nearest |
| `device.sendToHome()`, `device.pressBack()` | `device.home()`, `device.back()` |
| `device.setLocation(lat, lon)` | `device.setLocation({ latitude, longitude })` |
| `device.setOrientation('landscape')` | `device.setOrientation('landscape-left')` |
| `device.setBiometricEnrollment(true)` | `device.enrollBiometrics('faceid', true)` |
| `device.matchFace()`, `device.unmatchFace()` | `device.setBiometrics('faceid', 'match' \| 'nonmatch')` |
| `device.setStatusBar`, `device.setURLBlacklist` | No equivalent |
| `device.disableSynchronization()` | No equivalent. e2e waits through actions and retrying assertions. |
| `device.takeScreenshot()` | `app.screenshot('label')`, subject to the secret policy |
| `:ios:` / `:android:` in a test name | `{ platforms: ['ios'] }` on the test |

Where the behavior differs from Detox's:

- Actions and single-node reads or assertions need one match; several fail
  with `LOCATOR_AMBIGUOUS`. Narrow with `.filter()`, `.first()`, or `.nth()`,
  see [screen](/reference/screen).
- No `test.setup` or `{ session }` on a device, see
  [what differs from the web](/mobile#what-differs-from-the-web).

`by.text` is an exact match in Detox and `getByText` is exact here too.

## What to migrate first

Start with a flow that needs frequent maintenance. If its screens take time
to settle, configure the engine's
[`settle` and `transition` options](/reference/mobile#engine).
