---
title: From Selenium
description: Replace explicit waits and XPath with semantic queries, and page objects with goals.
---

A Selenium suite spends most of its lines waiting and locating. e2e removes
both. Every query polls, every action waits for its node, and the queries
name what a user sees rather than where it sits in the DOM. Tests are
TypeScript, so a Java or Python suite is rewritten rather than transpiled.
Run both side by side and retire each Selenium test as its e2e twin passes.

## Config

| Selenium | e2e |
| --- | --- |
| The URL in every `driver.get` | `playwright({ url })`, then relative paths |
| Starting the app in a script | `playwright({ url, command })`, see [Starting your app](/starting-your-app) |
| One driver per browser | One target per browser, `playwright({ browser: 'firefox' })` |
| Selenium Grid | `workers` for parallelism; `connect` attaches to a remote Chromium over CDP |
| `manage().window().setSize` | `playwright({ viewport })` |
| Implicit waits | Nothing to configure. `actionTimeout` and `assertionTimeout` are the deadlines |
| A page object for sign-in | `test.setup` and `{ session }`, see [Signing in](/authentication) |

## A test, before and after

```java title="Selenium"
driver.get("http://localhost:3000/login");
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
wait.until(visibilityOfElementLocated(By.id("username"))).sendKeys("admin@example.test");
driver.findElement(By.id("password")).sendKeys(System.getenv("ADMIN_PASSWORD"));
driver.findElement(By.xpath("//button[contains(., 'Sign in')]")).click();
wait.until(urlContains("/dashboard"));
assertEquals("Welcome back, admin!",
    driver.findElement(By.cssSelector(".greeting")).getText());
```

```ts title="e2e"
import { test } from '@e2edev/playwright';
import { expect, credentials } from 'e2e';

test('signs in', async ({ app, screen, web }) => {
  const admin = credentials.user('admin');
  await app.open('/login');
  await screen.getByLabel('Username').fill(admin.username);
  await screen.getByLabel('Password').fill(admin.password);
  await screen.getByRole('button', { name: 'Sign in' }).tap();
  await expect(web).toHaveURL('/dashboard');
  await expect(screen.getByRole('status')).toHaveText('Welcome back, admin!');
});
```

No wait objects, no XPath, and the password never appears in the test. A
flow with more variation than a login form is one line:
`await agent.act('sign in as {username}', { params: { username, password } })`.

## API map

| Selenium | e2e |
| --- | --- |
| `driver.get(url)` | `app.open(path)` |
| `driver.navigate().back()`, `.refresh()` | `app.back()`, `web.reload()` |
| `By.id`, `By.name` | `screen.getByTestId`, `screen.getByLabel` |
| `By.linkText`, `By.partialLinkText` | `screen.getByRole('link', { name })`, `name: /part/` |
| `By.cssSelector`, `By.xpath` | `web.locator('css or xpath')`, not portable |
| `findElements(...).size()` | `await locator.count()` |
| `findElements(...).get(n)` | `locator.nth(n)` |
| `.click()` | `.tap()` |
| `.sendKeys('text')` | `.fill('text')` replaces the content |
| `.sendKeys(Keys.ENTER)` | `.press('Enter')` |
| `.clear()` | `.clear()` |
| `new Select(el).selectByVisibleText` | `.selectOption({ label })` |
| `.getText()`, `.getAttribute()`, `.isDisplayed()` | `.textContent()`, `.getAttribute()`, `.isVisible()`, no retry |
| `wait.until(visibilityOf(...))` | `await expect(locator).toBeVisible()` |
| `wait.until(textToBe(...))` | `await expect(locator).toHaveText(...)` |
| `wait.until(urlContains(...))` | `await expect(web).toHaveURL(/.../)` |
| `Actions.moveToElement` | `.hover()` |
| `Actions.dragAndDrop` | `.dragTo(target)` |
| `Actions.keyDown(CONTROL).sendKeys('a')` | `.press('ControlOrMeta+a')` |
| `switchTo().frame()` | `web.frameLocator('#frame')` |
| `switchTo().alert().accept()` | `web.onDialog('accept')` before the action |
| `switchTo().window()` | No equivalent. Popups are unsupported |
| `executeScript` | `web.evaluate` |
| `manage().addCookie` | `web.setCookies` |
| `getScreenshotAs` | `app.screenshot('label')`, redacted |
| `Thread.sleep` | Nothing. Queries poll, actions wait, assertions retry |
| Page objects | A fixture from `test.extend`, or a goal for `agent.act` |

Where the behaviour differs from WebDriver's:

- `findElement` returns the first match. e2e fails with `LOCATOR_AMBIGUOUS`.
  Narrow with `.filter()`, `.first()`, or `{ visible: true }`.
- `textContent()` reads once and does not retry. Assert with `toHaveText()`,
  which polls until the deadline.

## What to migrate first

Page objects are the unit. One that wraps a multi-step flow becomes an
`agent.act` goal. One that wraps a single form becomes a few `screen` calls
or a fixture. Move the flows first, since that is where the explicit waits
live.
