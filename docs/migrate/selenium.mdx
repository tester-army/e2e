e2e replaces a Selenium suite with TypeScript tests. Locators find nodes by
role and label, and assertions retry until they pass or time out. A Java or
Python suite needs a rewrite, so run both suites and move one flow at a time.

## Port the config

<Note>Install e2e with the [quickstart](/quickstart). Only agent calls need a model, so the example below runs without one.</Note>

| Selenium | e2e |
| --- | --- |
| The URL in every `driver.get` | `app: { url }` on the target, then relative paths |
| Starting the app in a script | `app: { url, command }`, see [Starting your app](/web#starting-your-app) |
| One driver per browser | One target per browser, `web({ browser: 'firefox' })` |
| Selenium Grid | `workers` for parallelism; `web({ connect })` attaches to a remote Chromium over CDP, and a [browser provider](/browser#hosted-browsers) such as [Kernel](/integrations/kernel) leases hosted browsers |
| `manage().window().setSize` | `web({ viewport })` |
| Implicit waits | `actionTimeout` and `assertionTimeout` set action and assertion deadlines |
| A page object for sign-in | `test.setup` and `{ session }`, see [Signing in](/authentication) |

## Rewrite one flow

Start with one page object and the flows that use it.

```java title="Selenium"
driver.get("http://localhost:3000/login");
WebDriverWait wait = new WebDriverWait(driver, Duration.ofSeconds(10));
wait.until(visibilityOfElementLocated(By.id("username"))).sendKeys("admin@example.test");
driver.findElement(By.id("password")).sendKeys(System.getenv("ADMIN_PASSWORD"));
driver.findElement(By.xpath("//button[contains(., 'Sign in')]")).click();
wait.until(urlContains("/dashboard"));
assertEquals("Welcome back, admin!",
    driver.findElement(By.cssSelector(".greeting")).getText());
```

```ts title="e2e"
import { test } from '@e2e-dev/web';
import { expect, credentials } from 'e2e';

test('signs in', async ({ app, screen, browser }) => {
  const admin = credentials.user('admin');
  await app.open('/login');
  await screen.getByLabel('Username').fill(admin.username);
  await screen.getByLabel('Password').fill(admin.password);
  await screen.getByRole('button', 'Sign in').tap();
  await expect(browser).toHaveURL('/dashboard');
  await expect(screen.getByRole('status')).toHaveText('Welcome back, admin!');
});
```

Locator actions wait for their targets, so no explicit wait is left. The
password comes from [configured credentials](/authentication).

## Map each WebDriver call

| Selenium | e2e |
| --- | --- |
| `driver.get(url)` | `app.open(path)` |
| `driver.navigate().back()`, `.refresh()` | `app.back()`, `browser.reload()` |
| `By.id('x')` | `browser.locator('#x')`; or `web({ testIdAttribute: 'id' })` and `screen.getByTestId('x')` |
| `By.name('x')` | `browser.locator('[name="x"]')`, not portable; prefer a role or label |
| `By.linkText`, `By.partialLinkText` | `screen.getByRole('link', { name })`, `name: /part/` |
| `By.cssSelector`, `By.xpath` | `browser.locator('css or xpath')`, not portable |
| `findElements(...).size()` | `await locator.count()` |
| `findElements(...).get(n)` | `locator.nth(n)` |
| `.click()` | `.tap()` |
| `.sendKeys('text')` | `.fill('text')` replaces the content |
| `.sendKeys(Keys.ENTER)` | `.press('Enter')` |
| `.clear()` | `.clear()` |
| `new Select(el).selectByVisibleText` | `.selectOption({ label })` |
| `.getText()`, `.getAttribute()`, `.isDisplayed()` | `.textContent()`, `.getAttribute()`, `.isVisible()` read one time; `toHaveText()` retries |
| `wait.until(visibilityOf(...))` | `await expect(locator).toBeVisible()` |
| `wait.until(textToBe(...))` | `await expect(locator).toHaveText(...)` |
| `wait.until(urlContains(...))` | `await expect(browser).toHaveURL(/.../)` |
| `Actions.moveToElement` | `.hover()` |
| `Actions.dragAndDrop` | `.dragTo(target)` |
| `Actions.keyDown(CONTROL).sendKeys('a')` | `.press('ControlOrMeta+a')` |
| `switchTo().frame()` | `browser.frameLocator('#frame')` |
| `switchTo().alert().accept()` | `browser.onDialog('accept')` before the action |
| `switchTo().window()` | No equivalent. Popups are unsupported |
| `executeScript` | `browser.evaluate` |
| `manage().addCookie` | `browser.setCookies` |
| `getScreenshotAs` | `app.screenshot('label')`, redacted |
| `Thread.sleep` | Use a locator assertion for the condition you need |
| Page objects | A fixture from `test.extend`, or a goal for `agent.act` |

`findElement` takes the first match. e2e fails with `LOCATOR_AMBIGUOUS` on
several, so narrow with `.filter()`, `.first()`, or `.nth()`.
