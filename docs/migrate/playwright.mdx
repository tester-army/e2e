## Port the config

<Note>Install e2e and configure a model with the [quickstart](/quickstart).</Note>

A Playwright key such as `testDir`, `baseURL`, `use`, `webServer`, or
`projects` fails with a message that names the e2e key to use. The
[config reference](/reference/config) lists every key.

## Rewrite one spec

Start with a flow whose steps change often, such as a wizard or a checkout.
Stable Playwright tests can stay where they are.

```ts title="Playwright"
import { test, expect } from '@playwright/test';

test('checkout', async ({ page }) => {
  await page.goto('/cart');
  await page.getByRole('button', { name: 'Checkout' }).click();
  await page.getByLabel('Card number').fill('4242424242424242');
  await page.getByLabel('Expiry').fill('12/30');
  await page.getByLabel('CVC').fill('123');
  await page.getByRole('button', { name: 'Pay' }).click();
  await expect(page.getByRole('heading')).toHaveText('Order confirmed');
});
```

```ts title="e2e"
import { test } from '@e2e-dev/web';
import { expect } from 'e2e';

test('checkout', async ({ app, agent, screen }) => {
  await app.open('/cart');
  await agent.act('pay with the test card 4242 4242 4242 4242, expiry 12/30, CVC 123');
  await expect(screen.getByRole('heading')).toHaveText('Order confirmed');
});
```

The agent does the checkout steps and adapts when the form changes. A test
can also stay fully deterministic, with a `screen.getBy*` line for every
`page.getBy*` line.

## Map each API

`Status` is `same`, `renamed`, `web only`, `by design`, or `missing` with what
to do today. See [What differs on purpose](#what-differs-on-purpose) for the
`by design` rows. Calls on `browser` run only in a browser, so a test that
uses it declares `requires: ['browser']` and other targets skip it. Calls on
`screen`, `app`, `agent`, and `expect(locator)` run on every target.

## Port page objects

A page object takes `screen` for queries and actions, and `browser` for
keyboard, mouse, CSS selectors, and `evaluate`. Hand page objects out as
fixtures, so every test gets them without a `beforeEach`:

```ts title="tests/page-models/account-page.ts"
import type { Locator, Screen } from 'e2e';
import type { Browser } from '@e2e-dev/web';

export class AccountPage {
  readonly accountName: Locator;

  constructor(
    readonly screen: Screen,
    readonly browser: Browser,
  ) {
    this.accountName = screen.getByTestId('account-name');
  }

  async filterByNote(note: string) {
    await this.screen.getByRole('button', 'Filter').click();
    await this.screen.getByRole('button', 'Note').click();
    await this.browser.keyboard.type(note);
  }
}
```

```ts title="tests/fixtures.ts"
import { test as base } from '@e2e-dev/web';
import { AccountPage } from './page-models/account-page.ts';

export const test = base.extend<{ accountPage: AccountPage }>({
  accountPage: async ({ screen, browser }, use) => {
    await use(new AccountPage(screen, browser));
  },
});
```

A fixture that reads `browser` makes every test on that `test` web only,
named in its parameters or not. On a device target, each fails in
`beforeEach` with `UNSUPPORTED_CAPABILITY`. Give those tests `requires: ['browser']`, or keep
portable tests on the base `test`.

`locator.page()` has no counterpart, so pass `browser` with the locator. Drop
`newPage()` and `page.close()` from the hooks: every attempt starts in a fresh
context.

## What differs on purpose

- A string name is exact. Playwright's `getByRole` names, `getByLabel`,
  `getByPlaceholder`, and `getByText` match a case-insensitive substring, so
  `Save` also hits `Save as draft`. In e2e a string matches the whole text,
  case-sensitive. Pass `{ exact: false }` or a `RegExp` for a fragment. A
  query that misses passes a negated assertion, so check it with a positive
  one first. See [queries](/reference/screen#queries).

  ```ts
  // <button>Save changes</button>, <label>Email address <input></label>
  screen.getByRole('button', 'Save');                  // no match
  screen.getByRole('button', { name: 'Save', exact: false });    // matches
  screen.getByRole('button', 'save changes');          // no match, case differs
  screen.getByLabel('Email');                                    // no match
  ```
- Text reads are rendered text. On the web, `textContent()` and `toHaveText`
  read what `innerText` returns, where Playwright reads the DOM's
  `textContent`. Queries still match the source text: `getByText('Draft')`
  finds the tag below, `getByText('DRAFT')` does not. `browser.evaluate`
  reads the raw DOM text. See [locator reads](/reference/screen#locator-reads).

  ```ts
  // <span data-testid="tag" style="text-transform: uppercase">Draft</span>
  // <p data-testid="total">Total <span style="display: none">debug</span>42</p>
  // <p data-testid="address">Line one<br>Line two</p>
  await expect(screen.getByTestId('tag')).toHaveText('DRAFT');                 // Playwright: 'Draft'
  await expect(screen.getByTestId('total')).toHaveText('Total 42');            // Playwright: 'Total debug42'
  await expect(screen.getByTestId('address')).toHaveText('Line one Line two'); // Playwright: 'Line oneLine two'
  ```
- A node with no checked state is unchecked. `isChecked()` is `false` and
  `.not.toBeChecked()` passes on a button or a heading, where Playwright
  throws. Query a checkable control by role, so the query fails when the
  control changes kind.

  ```ts
  await expect(screen.getByRole('checkbox', 'Subscribe')).not.toBeChecked();
  ```
- `check()` and `uncheck()` read the state back until the action timeout,
  so a controlled checkbox that updates late passes. A click that removes the
  control passes too, where Playwright fails. Assert on what replaced it.
- One match or `LOCATOR_AMBIGUOUS`, `isVisible()` included, where Playwright
  reads the first match silently. See [screen](/reference/screen).
- `browser.evaluate` takes and returns JSON only, so the report can record
  and redact the result. Pass values in through `arg`.
- A password is a `Secret` with no string value, and the model never sees
  it. See [Signing in](/authentication).
- Sessions are per run. `test.setup` saves state under a name, one time per
  run and target, and `{ session }` restores it. The file is encrypted and
  deleted at cleanup, so there is no `.auth/user.json` to reuse across runs.
- No raw `Page` in tests. Nothing on a raw page is recorded, redacted, or
  masked. `surfaceOf(engine)` is for
  [custom executors](/executors#driving-the-page-yourself), not test code.

## Defaults that differ

| Setting | Playwright | e2e |
| --- | --- | --- |
| Test timeout | 30 s | 120 s, `timeout` |
| Action timeout | none | 30 s, `actionTimeout` |
| Expect timeout | 5 s | 5 s, `assertionTimeout` |
| Navigation timeout | none | 120 s, the test budget |
| Retries | 0 | 1 in CI, 0 locally |
| Workers | half the CPU cores | 1 in CI, half the CPU cores locally |
| Trace | `off` (`on-first-retry` in the scaffolded config) | `retain-on-failure` |
