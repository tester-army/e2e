---
title: From Playwright
description: Run e2e alongside Playwright and migrate tests one file at a time.
---

`@e2edev/web` uses your installed Playwright when its version satisfies
the engine's peer dependency. Both test runners can stay in the same project.
e2e uses `e2e.config.ts` and finds `tests/**/*.e2e.ts` by default. Keep the two
runners' file patterns separate.

Follow the [quickstart](/quickstart) to install e2e and configure a model for
agent calls.

## Config

| Playwright | e2e |
| --- | --- |
| `use.baseURL` | `web({ url })` |
| `webServer` | `web({ url, command })`, see [Starting your app](/starting-your-app) |
| `projects` | `targets`, one engine instance each |
| `use.viewport`, `use.browserName` | `web({ viewport, browser })` |
| `testIdAttribute` | `web({ testIdAttribute })` |
| `retries`, `workers`, `timeout` | The same names at the top level |
| `storageState` | `test.setup` and `{ session }`, see [Signing in](/authentication) |
| `reporter` | `reporters: ['list', 'junit']` |

## Command line

| Playwright | e2e |
| --- | --- |
| `npx playwright test tests/checkout.spec.ts` | `npx e2e run tests/checkout.e2e.ts`; a directory, a bare file name, or a quoted glob also selects files |
| `npx playwright test tests/checkout.spec.ts:12` | `npx e2e run tests/checkout.e2e.ts:12`, the test whose `test(` call opens on that line |
| `--project chromium` | `--target web`, the name in `targets` |
| `--grep`, `--grep-invert` | The same, matched against the describe titles and the test title joined by spaces; tags are `--tag` and `--exclude-tag` |
| `--headed`, `--workers`, `--retries`, `--pass-with-no-tests`, `--last-failed`, `--shard`, `--max-failures` | The same names; `--shard` keeps serial groups together |
| `--reporter junit` | `--reporter list,junit` |
| `--ui`, `--debug` | `npx e2e mcp` gives a coding agent a live session; `--debug` prints timings and the agent step table |

## A test, before and after

```ts title="Playwright"
import { test, expect } from '@playwright/test';

test('checkout', async ({ page }) => {
  await page.goto('/cart');
  await page.getByRole('button', { name: 'Checkout' }).click();
  await page.getByLabel('Card number').fill('4242424242424242');
  await page.getByLabel('Expiry').fill('12/30');
  await page.getByLabel('CVC').fill('123');
  await page.getByRole('button', { name: 'Pay' }).click();
  await expect(page.getByRole('heading')).toHaveText('Order confirmed');
});
```

```ts title="e2e"
import { test } from '@e2edev/web';
import { expect } from 'e2e';

test('checkout', async ({ app, agent, screen }) => {
  await app.open('/cart');
  await agent.act('pay with the test card 4242 4242 4242 4242, expiry 12/30, CVC 123');
  await expect(screen.getByRole('heading')).toHaveText('Order confirmed');
});
```

The navigation and final assertion stay explicit. The agent handles the
checkout interactions and can adapt when the form changes.

## API map

| Playwright | e2e |
| --- | --- |
| `page.goto(path)` | `app.open(path)` |
| `page.getByRole`, `getByLabel`, `getByText`, `getByTestId`, `getByPlaceholder` | The same on `screen` |
| `locator.click()` | `locator.tap()`; `click()` is an alias |
| `locator.click({ position })` | `locator.tap({ position })` |
| `page.mouse.click(x, y)` | `screen.tapAt({ x, y })` |
| `page.mouse` down, move, up | `screen.swipe({ from, to })` |
| `page.locator('css')` | `web.locator('css')`, not portable |
| `page.frameLocator` | `web.frameLocator` |
| `page.route`, `page.waitForResponse` | `web.route`, `web.waitForResponse` |
| `page.on('dialog')` | `web.onDialog('accept')` |
| `page.waitForEvent('download')` | `web.waitForDownload(() => ...)` |
| `page.evaluate` | `web.evaluate` |
| `context.addCookies` | `web.setCookies` |
| `page.setViewportSize` | `web.setViewport` |
| `expect(page).toHaveURL` | `expect(web).toHaveURL` |
| `expect(locator).toHaveScreenshot()` | No pixel-diff equivalent. Use `agent.assert('...', { vision: true })` for a visual judgment. |
| `page.waitForTimeout` | Use a locator assertion for the condition you need |
| `test.extend` | `test.extend`, same shape |

Where the behaviour differs from Playwright's:

- `getByText` matches exactly by default. Pass `{ exact: false }` for
  Playwright's substring match.
- Single-node reads and assertions fail on multiple matches. Narrow with
  `.filter()`, `.first()`, or `{ visible: true }`.
- A password is a `Secret` with no string value. It comes from
  `credentials.user('admin').password` and goes into `fill` or an `act`
  param.

## What to migrate first

Start with a flow whose interaction sequence changes often, such as a wizard
or checkout. Give `agent.act` the goal and verify the result with `expect`.
Tests that already work well can remain in Playwright.
