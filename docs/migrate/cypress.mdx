## Port the config

<Note>Install e2e and configure a model with the [quickstart](/quickstart). The example below uses an agent call.</Note>

| Cypress | e2e |
| --- | --- |
| `baseUrl`, `start-server-and-test` | `app: { url, command }` on the target, see [Starting your app](/web#starting-your-app) |
| `data-cy` selectors | `web({ testIdAttribute: 'data-cy' })`, then `screen.getByTestId` |
| `viewportWidth`, `viewportHeight`, `cy.visit(url, { auth, headers })` | `web({ viewport, basicAuth, headers })` |
| `retries: { runMode: 2, openMode: 0 }` | `retries: process.env.CI ? 2 : 0`, a number only |
| `env`, `Cypress.env()`, `cypress.env.json` | `process.env`; sign-in values go in `credentials` and `secrets`, see [Authentication](/authentication) |
| `cypress run --browser firefox` | A target with `web({ browser: 'firefox' })`, run with `--target <name>` |

```ts title="e2e.config.ts"
import type { E2EConfig } from 'e2e';
import { web } from '@e2e-dev/web';

export default {
  targets: [{
    engine: web({ testIdAttribute: 'data-cy' }),
    app: { url: 'http://localhost:3000' },
  }],
} satisfies E2EConfig;
```

## Rewrite one spec

```js title="Cypress"
describe('todos', () => {
  it('completes one', () => {
    cy.visit('/todos');
    cy.get('[data-cy=new-todo]').type('Buy milk{enter}');
    cy.get('[data-cy=new-todo]').type('Walk the dog{enter}');
    cy.contains('li', 'Buy milk').find('[data-cy=toggle]').click();
    cy.get('[data-cy=todo]').should('have.length', 2);
    cy.contains('1 item left').should('be.visible');
  });
});
```

```ts title="e2e"
import { describe, test } from '@e2e-dev/web';
import { expect } from 'e2e';

describe('todos', () => {
  test('completes one', async ({ app, agent, screen }) => {
    await app.open('/todos');
    await agent.act('add todos "Buy milk" and "Walk the dog"');
    await expect(screen.getByTestId('todo')).toHaveCount(2);
    await agent.act('complete "Buy milk"');
    await expect(screen.getByText('1 item left')).toBeVisible();
  });
});
```

## Map each command

| Cypress | e2e |
| --- | --- |
| `cy.visit(path)`, `cy.reload()`, `cy.viewport(w, h)`, `cy.setCookie()` | `app.open(path)`, `browser.reload()`, `browser.setViewport({ width, height })`, `browser.setCookies()` |
| `cy.get('[data-cy=x]')`, `.find('[data-cy=x]')` | `screen.getByTestId('x')`, `row.getByTestId('x')` |
| `cy.get('css')` | `browser.locator('css')`, web only; prefer a role or label |
| `cy.contains('text')`, `cy.contains('li', 'text')` | `screen.getByText('text', { exact: false })`, `screen.getByRole('listitem').filter({ hasText: 'text' })` |
| `.click()`, `.dblclick()`, `.clear()`, `.check()`, `.uncheck()`, `.focus()`, `.first()`, `.last()`, `.scrollIntoView()` | The same |
| `.rightclick()`, `.eq(n)`, `.selectFile(path)` | `.secondaryTap()`, `.nth(n)`, `.setInputFiles(path)` |
| `.type('text')`, `.type('{enter}')`, `.clear().type('text')` | `.pressSequentially('text')` appends with key events, `.press('Enter')`, `.fill('text')` |
| `.select('Pro')` | `.selectOption('Pro')` matches the label; a value needs `{ value: 'pro' }`, an index `{ index: 1 }` |
| `.should('be.visible')`, `be.checked`, `be.disabled`, `be.focused`, `exist` | `await expect(locator).toBeVisible()`, `toBeChecked()`, `toBeDisabled()`, `toBeFocused()`, `toBeAttached()` |
| `have.text`, `contain`, `have.value`, `have.attr`, `have.length`, `not.exist` | `toHaveText`, `toContainText`, `toHaveValue`, `toHaveAttribute`, `toHaveCount(n)`, `toHaveCount(0)` |
| `cy.url().should('include', p)`, `cy.title()` | `expect(browser).toHaveURL(/p/)`, `expect(browser).toHaveTitle(t)` |
| `cy.intercept('/api/users', body)` | `browser.route('**/api/users', route => route.fulfill({ json: body }))`, a glob on the full URL |
| `cy.on('window:confirm')`, `cy.on('window:alert')` | `await browser.onDialog('accept')` before the action, `'dismiss'` to cancel |
| `cy.session` | `test.setup` and `{ session }` |
| `cy.task`, `cy.exec`, `cy.request`, `cy.fixture` | Node code: `fetch`, `fs`, your database client, `import data from './fixture.json'` |
| `Cypress.Commands.add` | A function, or a fixture from `test.extend` |

## What e2e doesn't have yet

Planned gaps are on the roadmap, and Not yet gaps have no date. Not planned gaps are left out on purpose.

### Planned

| Cypress | Use today |
| --- | --- |
| `.find('css')`, `.filter('css')`, `.not('css')` | Chain a `getBy*` query, or write one selector: `browser.locator('li.active >> .title')` |
| `.invoke()`, `.its()`, `.then($el => ...)`, `.should($el => ...)` | `getAttribute()`, `textContent()`, `inputValue()`, else `browser.evaluate`; wrap in `expect.poll` to retry |
| `have.class`, `have.css`, `have.prop`, `be.empty` | `expect(browser).toHaveClass(locator, /regexp/)`, `toHaveText('')`; else `expect.poll(() => browser.evaluate(...))` |
| `.trigger()`, `cy.scrollTo()`, `.blur()` | `hover()`, `dragTo()`, `scrollIntoView()`, `press('Tab')`; else `browser.evaluate` |
| `cy.intercept('POST', url)` and other method or header matchers | Check `route.request.method` in the handler, else call `route.fallback()` |
| `cy.wait('@alias')`, `.its('request.body')`, `@alias.all` | Start `browser.waitForResponse(pattern)` before the action; read the request in a `browser.route` handler |
| `Cypress.on('uncaught:exception')` | An app error doesn't fail a test. To fail on one, collect `window.onerror` in `browser.addInitScript` |
| `--browser chrome`, `edge`, `electron`, `before:browser:launch` | `web({ browser: 'chromium' })`, or attach to your own Chrome with `web({ connect: { cdpEndpoint } })` |
| `cypress open`, time-travel snapshots | `npx e2e run --headed --watch`, or `--step`; the [trace page](/debugging#traces) shows each step after the run |
| `before()` and `after()` that drive the app, `describe.only` | UI setup in `beforeEach` or `test.setup`; `test.only` on each test |
| `cy.clock()`, `cy.tick()` | A fake-timers script loaded with `browser.addInitScript({ path })`, driven by `browser.evaluate` |

### Not yet

| Cypress | Use today |
| --- | --- |
| `.parent()`, `.closest()`, `.siblings()`, `.next()` | Locate the ancestor and narrow it: `card.filter({ has: child })` |
| `{ force: true }` | Act on the visible label, or `tap({ position })`, which skips the actionability checks |
| `cy.request()` with the browser's cookies | Send `browser.cookies()` with `fetch`, see [Signed-in requests](/api-testing#signed-in-requests) |
| `supportFile`, `blockHosts` | A shared `test` from `test.extend` that every file imports; abort hosts there with `browser.route` |
| `cypress run --record --parallel`, Cypress Cloud | `--shard` on each CI job, the `junit` and `github()` reporters, `.e2e` uploaded as an artifact |
| `cy.visit()` failing on a 4xx or 5xx page | `app.open` ignores the status. Assert on the page content |
| `cy.stub()`, `cy.spy()`, `cy.clearLocalStorage()` | Wrap the function in `browser.addInitScript`; read calls or clear storage with `browser.evaluate` |

### Not planned

| Cypress | Use instead |
| --- | --- |
| `cy.wait(ms)` | A locator assertion on the state the test waits for |
| `it`, `context`, `specify`, `xit` | `test`, `describe`, `test.skip` |
| chai `expect(x).to...`, `assert.*` | `toEqual`, `toContain`, `toMatchObject` on `expect(value)`, or import `chai` yourself |
| `cy.window()`, `cy.document()`, `onBeforeLoad(win)` | `browser.evaluate` and `browser.addInitScript` with JSON values. Tests run in Node, not in the page |
| Mocha reporters, `reporterOptions` | `list`, `json`, `junit`, `markdown`, `htmlReporter()`, `github()`, or your own [reporter](/reference/reporters) |
| Cucumber `.feature` files, `file:preprocessor` | Rewrite features as tests. TypeScript needs no preprocessor |
| Component testing | Keep it in Cypress. e2e tests a running app |

## What differs on purpose

- There is no command chain. Await each call and keep the locator or value in a variable, where Cypress uses `.as()`, `.within()`, or `.then()`.
- [Locators](/reference/screen) are strict. An action or single-node assertion on several matches fails with `LOCATOR_AMBIGUOUS`. Narrow with `.filter()`, `.first()`, or `.nth()`, or loop over `await locator.all()`.
- A string in a query matches the whole text. `{ exact: false }` matches a fragment in any case. `cy.contains` is case-sensitive and takes the first match, so pass a RegExp or add `.first()`.
- Text matchers compare the rendered text. CSS `text-transform` applies and hidden children are left out, see [locator reads](/reference/screen#locator-reads).
- Dialogs are not accepted for you. An `alert` or `confirm` with no handler fails the next step, where Cypress accepts it.

## Defaults that differ

| Setting | Cypress | e2e |
| --- | --- | --- |
| Viewport | 1000 by 660 | 1280 by 720 |
| Action and assertion timeouts | `defaultCommandTimeout`, 4 s | `actionTimeout` 30 s, `assertionTimeout` 5 s |
| Retries in CI | `0` | `1` |
