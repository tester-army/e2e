e2e is an open source testing framework for web and mobile apps. A test can
use exact [locators](/core-concepts#locators) and
[assertions](/reference/expect#locator-matchers), [goals](/core-concepts#goals)
in natural language that an agent completes, or both in the same test.

```ts title="tests/checkout.e2e.ts"
import { test, expect } from 'e2e';

test('a member upgrades to Pro', async ({ app, agent, screen }) => {
  await app.open('/settings/billing');

  await agent.act('upgrade the workspace to the Pro plan');
  await agent.assert('the invoice preview shows a prorated amount');

  await expect(screen.getByRole('status')).toContainText('Pro');
});
```

## Why e2e

- **Less time on tests.** Write a goal instead of a script of selectors and
  waits. When the UI changes, the agent adapts, so you fix fewer tests.
- **Less risk.** Cover more of the flows your users depend on, on web and
  mobile, and catch regressions before they reach production.
- **Cheap runs.** Verified `agent.act` steps [replay from a cache](/cache)
  with no model calls, so more flows don't mean a bigger token bill or a
  slower CI.

## How it works

- **Targets.** Each test runs one time per target, such as Chromium or an
  iPhone simulator. The [web engine](/web) drives browsers through
  Playwright. The [mobile engine](/mobile) drives iOS simulators and Android
  emulators through agent-device. You can also
  [write your own](/writing-an-engine).
- **Agent steps.** `agent.act` completes a goal. `agent.assert`,
  `agent.waitFor`, and `agent.extract` judge the screen. Use your own
  [subscription](/subscriptions), [API key, or local model](/models). Tests
  without agent steps need no model.
- **Cache.** e2e records an `act` step when a later check passes. The next
  run replays it, and hands back to the agent when the app changed.
  `assert`, `waitFor`, and `extract` always call the model.
- **Reports.** The runner [redacts registered secrets](/security) from model
  input. It records steps, failures, and artifacts in a
  [report](/debugging) that you or your coding agent can read.
