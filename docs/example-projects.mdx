Each example is a standalone greeting app with three locator tests and two
agent tests. The tests enter a name, press Greet, and check the result. The
projects install the published e2e packages from npm and work outside this
repository.

## Run an example

Follow the project's README to install, build, and run it. The config and
tests live beside the app. The SwiftUI, Jetpack Compose, Kotlin
Multiplatform, and Flutter projects keep them in an `e2e/` folder.

The locator tests need no model. The agent tests use Vercel AI Gateway. Set
`AI_GATEWAY_API_KEY` to run them. Without it, they skip.
