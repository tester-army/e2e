Each example is a standalone greeting app with three locator tests and two
agent tests. Enter a name, press Greet, and check the result. The projects
install published e2e packages from npm and work outside this repository.

Follow each project's README for installation, builds, and run commands.
The config and tests live beside the app. The SwiftUI, Jetpack Compose,
Kotlin Multiplatform, and Flutter projects keep them in an `e2e/` folder.

Locator tests need no model. Set `AI_GATEWAY_API_KEY` to run the agent
tests; without it, those tests skip. See [Models](/models) for model setup
and the [Quickstart](/quickstart) to add e2e to your own app.
