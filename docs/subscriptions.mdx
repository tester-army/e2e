Use a plan that you already pay for to run agent steps. Agent calls use the
usage limits of your plan.

| Plan | How to connect |
| --- | --- |
| ChatGPT Plus or Pro | `npx e2e login openai` |
| GitHub Copilot | `npx e2e login github-copilot` |
| OpenCode Console (OpenCode Zen and OpenCode Go) | `npx e2e login opencode-console` |
| SuperGrok or X Premium+ | `npx e2e login spacexai` |
| Claude Max or Team (Claude Code) | API key from the plan's monthly API credits |

## Set up

For a new project, run `e2e init` and select your plan. See the
[quickstart](/quickstart).

For an existing project, select your plan below. Install the packages, sign
in, and set the model as `agents: { default: agent }` in `e2e.config.ts`.

## Pick a model

To see the model ids that your login can use, run `e2e models`:

<CodeGroup>
```bash npm
npx e2e models            # every stored login
npx e2e models openai     # one provider
```

```bash pnpm
pnpm exec e2e models            # every stored login
pnpm exec e2e models openai     # one provider
```

```bash bun
bunx e2e models            # every stored login
bunx e2e models openai     # one provider
```
</CodeGroup>

The id is not always the name that the vendor's app shows.

- **Copilot** marks models that `copilot()` cannot call. `not enabled`: turn
  the model on in your Copilot settings on GitHub, or ask your organization
  admin if they manage your seat. `no chat or responses`: use a different
  model.
- **OpenCode Console** ids without a prefix are Zen models, paid from the
  workspace's credits. Ids with `go/` are Go models, paid from the Go
  subscription, and listed only if you have it. The list leaves out models
  your workspace turned off and Zen's free models. Set `providerOptions`
  under `opencode` for chat completions models, and under `openai`,
  `anthropic`, or `google` for the others.

## Sign-in help

- ChatGPT opens a browser. To use a device code, add `--device`.
- Copilot uses your GitHub CLI login. Without `gh`, give `--client-id` for
  your own GitHub OAuth app with device flow enabled. For GitHub Enterprise, add `--enterprise-url`.
- OpenCode Console shows a device code. Approve it and select the
  workspace. The page shows e2e as an unknown client. To change the workspace, run `npx e2e logout opencode-console`
  and sign in again.
- SuperGrok shows a device code and the URL where you enter it.

Run `npx e2e login` to see the accounts that are signed in. Run
`npx e2e logout` to remove a login. If a saved login stops working, the step
fails with `MODEL_PROVIDER_FAILED`, and the message shows the
`npx e2e login <provider>` command to run.

## CI

Use API keys in CI:

- Claude Max or Team: set `ANTHROPIC_API_KEY`.
- OpenCode Console: create a service account API key in the Console
  (Service Accounts, then API Keys) and set it as `OPENCODE_API_KEY`.
- ChatGPT, Copilot, and SuperGrok: use an [API provider](/models).

[`E2E_OAUTH_CREDENTIALS`](/reference/environment) can give a stored login to
CI, but e2e does not save refreshed tokens back to it. A login with a
rotating refresh token works there only for a limited time. For all
sign-in flags, see the [CLI reference](/reference/cli#e2e-login).
