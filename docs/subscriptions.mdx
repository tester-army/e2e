Run agent steps on a plan you already pay for. Sign in one time, then use
the plan's model in `e2e.config.ts`.

| Plan | How to connect |
| --- | --- |
| ChatGPT Plus or Pro | `npx e2e login openai` |
| GitHub Copilot | `npx e2e login github-copilot` |
| OpenCode Console (OpenCode Zen and OpenCode Go) | `npx e2e login opencode-console` |
| SuperGrok or X Premium+ | `npx e2e login spacexai` |
| Claude Max or Team (Claude Code) | API key, paid from the plan's monthly API credits, not its usage limits |

## Set up

For a new project, run `e2e init` and select your plan
([quickstart](/quickstart)). For an existing project, install the packages,
sign in, and set `agents: { default: agent }` in `e2e.config.ts`.

## Pick a model

`e2e models` lists the model ids your login can use:

<CodeGroup>
```bash npm
npx e2e models            # every stored login
npx e2e models openai     # one provider
```

```bash pnpm
pnpm exec e2e models            # every stored login
pnpm exec e2e models openai     # one provider
```

```bash bun
bunx e2e models            # every stored login
bunx e2e models openai     # one provider
```
</CodeGroup>

The id is not always the name the vendor's app shows.

- **Copilot** marks the models `copilot()` can't call. For `not enabled`,
  turn the model on in your Copilot settings on GitHub, or ask the admin who
  manages your seat. For `no chat or responses`, use a different model.
- **OpenCode Console** lists `go/` models only if you have Go. It leaves out
  models your workspace turned off, and Zen's free models. Key
  `providerOptions` by `opencode` for chat completions models, else by
  `openai`, `anthropic`, or `google`.

## Sign-in help

- ChatGPT opens a browser. To use a device code, add `--device`.
- Copilot uses your GitHub CLI login. Without `gh`, pass `--client-id` with
  your own GitHub OAuth app that has device flow on. For GitHub Enterprise,
  add `--enterprise-url`.
- OpenCode Console shows a device code. Approve it and select the
  workspace. The page shows e2e as an unknown client. To change the
  workspace, run `npx e2e logout opencode-console` and sign in again.
- SuperGrok shows a device code and the URL where you enter it.

`npx e2e login` with no provider opens a picker that shows which accounts
are signed in. `npx e2e logout` removes a login. When a saved login stops
working, the step fails with `MODEL_PROVIDER_FAILED`, and the message gives
the `npx e2e login <provider>` command to run. See the
[CLI reference](/reference/cli#e2e-login) for every flag.

## CI

Use API keys in CI. Claude Max or Team already uses one. For OpenCode
Console, create a service account API key in the Console (Service Accounts,
then API Keys) and set it as `OPENCODE_API_KEY`. For ChatGPT, Copilot, and
SuperGrok, use an [API provider](/models).

[`E2E_OAUTH_CREDENTIALS`](/reference/environment) can give a stored login to
CI, but e2e doesn't save refreshed tokens back to it. A login with a
rotating refresh token works there only for a limited time.
