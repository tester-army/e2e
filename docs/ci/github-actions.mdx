## Web

This workflow runs deterministic and agent tests in one job. It assumes
that your config has a [command](/web#starting-your-app) that starts the
app, and that AI Gateway makes the model calls. The model key and the user
credentials come from repository secrets:

```yaml title=".github/workflows/e2e.yml" expandable
name: e2e

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

concurrency:
  group: ${{ github.workflow }}-${{ github.ref }}
  cancel-in-progress: ${{ github.event_name == 'pull_request' }}

jobs:
  e2e:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: pnpm/action-setup@9fd676a19091d4595eefd76e4bd31c97133911f1 # v4.2.0
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 26
          cache: pnpm
      - run: pnpm install --frozen-lockfile

      - name: Install browsers
        run: pnpm exec e2e-web install chromium --with-deps

      - name: Run e2e
        run: npx e2e run --reporter list,junit
        env:
          APP_URL: http://127.0.0.1:3000
          AI_GATEWAY_API_KEY: ${{ secrets.AI_GATEWAY_API_KEY }}
          E2E_USER_ADMIN_USERNAME: ${{ secrets.E2E_USER_ADMIN_USERNAME }}
          E2E_USER_ADMIN_PASSWORD: ${{ secrets.E2E_USER_ADMIN_PASSWORD }}

      - name: Upload report
        if: ${{ !cancelled() }}
        uses: actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1
        with:
          name: e2e-report
          path: |
            .e2e/report.json
            .e2e/junit.xml
          if-no-files-found: warn

      - name: Upload artifacts
        if: ${{ !cancelled() }}
        uses: actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1
        with:
          name: e2e-artifacts
          path: .e2e/results
          if-no-files-found: warn
          retention-days: 7
```

The workflow pins each action to a commit SHA and installs from the
lockfile, so `npx e2e` runs the installed version. The
[install command](/reference/web#installing-browsers) downloads the browsers
for the Playwright version the engine pins, with their system libraries.

The upload steps run on each run that isn't cancelled. A test that failed
and then passed on retry keeps its evidence.

## iOS and Android

This workflow has one job for each platform. It follows the rules in
[Mobile jobs](/ci#mobile-jobs).

The iOS job builds the app with `xcodebuild`. Another build command works
if it writes a simulator `.app` and doesn't start the app. For Expo,
`npx expo run:ios --configuration Release --device generic --no-bundler --output build/ios`
builds without a simulator and writes the `.app` under `build/ios`.

```yaml title=".github/workflows/e2e-mobile.yml" expandable
name: e2e mobile

on:
  pull_request:
  push:
    branches: [main]

permissions:
  contents: read

jobs:
  ios:
    runs-on: macos-26
    timeout-minutes: 60
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 26
          cache: npm
      - run: npm ci
      - run: pod install
        working-directory: ios

      - name: Build for the simulator
        run: |
          xcodebuild -workspace ios/MyApp.xcworkspace -scheme MyApp \
            -configuration Release -sdk iphonesimulator \
            -destination 'generic/platform=iOS Simulator' \
            -derivedDataPath build
      - uses: actions/cache@55cc8345863c7cc4c66a329aec7e433d2d1c52a9 # v6.1.0
        with:
          path: ~/.agent-device
          key: agent-device-${{ runner.os }}-${{ hashFiles('package-lock.json') }}

      - name: Boot a simulator and install the app
        run: |
          UDID=$(xcrun simctl create e2e "iPhone 17" com.apple.CoreSimulator.SimRuntime.iOS-26-5)
          xcrun simctl bootstatus "$UDID" -b
          xcrun simctl install "$UDID" build/Build/Products/Release-iphonesimulator/MyApp.app

      - run: npx e2e run --target ios --reporter list,junit
        env:
          AI_GATEWAY_API_KEY: ${{ secrets.AI_GATEWAY_API_KEY }}

      - uses: actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1
        if: ${{ !cancelled() }}
        with:
          name: e2e-ios
          path: .e2e
          if-no-files-found: warn

  android:
    runs-on: ubuntu-latest
    timeout-minutes: 60
    steps:
      - uses: actions/checkout@3d3c42e5aac5ba805825da76410c181273ba90b1 # v7.0.1
      - uses: actions/setup-node@820762786026740c76f36085b0efc47a31fe5020 # v7.0.0
        with:
          node-version: 26
          cache: npm
      - uses: actions/setup-java@de7274f081f381c8f8158605e0321c36c376e2e6 # v6.0.1
        with:
          distribution: temurin
          java-version: 17
      - run: npm ci

      - name: Enable KVM
        run: |
          echo 'KERNEL=="kvm", GROUP="kvm", MODE="0666", OPTIONS+="static_node=kvm"' | sudo tee /etc/udev/rules.d/99-kvm4all.rules
          sudo udevadm control --reload-rules
          sudo udevadm trigger --name-match=kvm
      # React Native and Expo templates sign release builds with the debug keystore.
      - name: Build the APK
        run: cd android && ./gradlew :app:assembleRelease

      - name: Run on an emulator
        uses: reactivecircus/android-emulator-runner@a421e43855164a8197daf9d8d40fe71c6996bb0d # v2.38.0
        with:
          api-level: 36
          arch: x86_64
          target: google_apis
          profile: pixel_7
          emulator-options: -no-window -gpu swiftshader_indirect -no-snapshot -noaudio -no-boot-anim
          disable-animations: true
          script: |
            adb install -r android/app/build/outputs/apk/release/app-release.apk
            npx e2e run --target android --reporter list,junit
        env:
          AI_GATEWAY_API_KEY: ${{ secrets.AI_GATEWAY_API_KEY }}

      - uses: actions/upload-artifact@043fb46d1a93c77aae656e7c1c64a875d1fc6a0a # v7.0.1
        if: ${{ !cancelled() }}
        with:
          name: e2e-android
          path: .e2e
          if-no-files-found: warn
```

The emulator runner action boots the emulator and runs each `script` line
in a new shell. It stops the emulator when the step ends, so the install
and the run must be in the same step.

This repository runs its own mobile suites the same way.
[`mobile.yml`](https://github.com/tester-army/e2e/blob/main/.github/workflows/mobile.yml)
also caches the Expo build for each native fingerprint, boots two
simulators for two workers, and runs the failed tests again with
`--last-failed`.

## Pull request comments

Add the [`@e2e-dev/github` reporter](/github) to post the results of each
job as one comment on the pull request. A rerun updates the same comment,
and the reporter also writes the results to the job summary.

To post, the job needs `pull-requests: write` and `GITHUB_TOKEN` in the env
of the test step. The workflows above have read-only permissions. See
[Setup](/github#setup). A `pull_request` run from a fork gets a read-only
token, so the reporter can't post there. See
[When nothing is posted](/github#when-nothing-is-posted).
