# Connected calibration did not admit the baseline

The six revised fixtures passed preparation, but calibration did not admit the twelve-session baseline. The decision remains `unresolved-operational-feasibility`. No baseline budget was sealed, no baseline author started, and no comparison cohort ran. This capture provides no evidence about defect detection or the benefit of inspecting unit tests.

## Frozen design

The connected study contains six product tickets and two fixed UI integration regressions per ticket. Addresses, promotions, expenses, and catalog search are informative families. Orders and wishlist are safeguards. The five shop tickets share the same complete shop implementation and product contract. Expenses uses a separate product. Authors receive current requirements, correct source, the ticket's lower tests, and the installed E2E skill. They may inspect lower tests voluntarily.

The bank froze at source revision `fc3214f1a59c369ec683905a96e6dd535978d011`. Its SHA-256 is `2bda62ec651f65d3b2d2b8322b249f47cde9a869902ac5acf6258f5a617a8127`. The copied runtime hash is `ef2de839f7ac0f712a250f371f70d572d8e79b527d6183c33d4bedb89d533b33`. Later publication edits do not change those inputs.

Preparation passed 36 lower-test launches and 108 browser controls through the copied built CLI. Strong controls reached both intended regression assertions in both repeats. Meaningful weaker journeys passed both changed versions. Wrong assertions, unrelated failures, and broken startup received their expected classifications. All 108 controls had clean natural and owned-finalizer cleanup and zero runtime model usage.

## Two operational failures

The catalog journal contains valid LF-delimited JSON. The external operator's replay reader used Python `str.splitlines()`, which also splits literal Unicode NEL characters inside valid JSON strings. Its 720 physical records became 724 fragments, producing an unterminated-string error. All 3,159 physical records across the six journals parse with LF framing. Model-free reproductions isolate the same problem with literal U+0085, U+2028, and U+2029. The failed terminal stays failed even though this diagnosis explains it. A reader patch must receive a new operator identity before another study can use it.

The contributor also invoked validation with an absolute Node executable without adding its directory to `PATH`. The configured app command launches `node` by name. All ten launched validation cells therefore failed before test selection with `APP_UNREACHABLE` and `spawn node ENOENT`. A model-free child-process probe reproduced that failure and passed after adding the pinned directory to `PATH`. This was an invocation error, not an observed defect in the authored tests. The ten failed cells remain unchanged. No validation cell was rerun to obtain a preferred outcome.

The baseline-sealing command rejected the calibration set with the expected no-subset error. All twelve prospective baseline slots and their 72 planned execution cells remain unstarted. No calibration suite ran against a changed app. There are no baseline outcome packets to judge.

## Implementation and verification

The contribution adds the connected fixtures, frozen bank, correct-only calibration, all-slot reporting, and separate human attribution records. During preparation, a real CLI probe exposed a worker-disposal bug. The scheduler now uses the configured disposal grace instead of a fixed ten-second shutdown limit. A patch changeset records that runtime change.

Verification passed the full repository check, 13 fixture tests, ten study-policy tests, 27 external operator tests, and 45 scheduler tests on their retained source revisions. Actual rebuilt CLI probes verified disposal within the configured grace and an explicit cleanup-timeout error beyond it. These checks do not certify arbitrary hung workers or hosted providers. An earlier historical control failure passed unchanged on a quiet rerun; its original cause remains unknown.

Before publication, the default full core unit run passed 2,747 tests, skipped one, and failed two unchanged secret-redaction timing assertions. Both exceeded their existing five-second limit. The same suite with three workers passed 2,749 tests and skipped one. That bounded-concurrency diagnostic preserves the original failures and does not establish their cause. No threshold or test source changed. The built testbed passed 79 tests with one skip, and the deterministic web benchmark passed all 91 tests.

## Decision for the draft PR

Keep the PR draft and the inspection instruction experimental. The fixtures are implemented and their controls passed, but baseline headroom and comparative benefit remain unmeasured. Another cohort needs a newly identified operator, a verified invocation environment, a fresh frozen bank, and fresh calibration first attempts. This capture cannot authorize the sixty-run comparison.

The contributor retains the exact exports, native event journals, receipts, source and runtime reconstruction, failed validation cells, diagnosis proofs, and decision trail outside the repository. These public aggregates do not independently reproduce or audit the private live capture.
