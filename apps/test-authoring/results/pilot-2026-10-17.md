# First test-authoring pilot

The inspection instruction changed reading behavior but produced no observed improvement in defect detection on this corpus. Both arms provisionally detected all twenty assigned regressions. Production authoring guidance remains unchanged.

## Observations

Each cell contains five fresh authoring sessions. A provisional detection requires a correct-app pass, a relevant changed-app failure, matching test selection, known budget compliance, and exploratory blinded AI attribution.

All forty first attempts completed normally and returned a test. No submission was missing or invalid, and all observed authoring consumption was within the declared limits. The submissions contained 56 test cases. Correct and changed applications selected and executed the same cases, with one worker, zero retries, cache off, and no runtime model calls. Every submission passed the correct application and failed the changed application. All twenty matched pairs tied on provisional detection.

An external transcript extractor matched the distinctive lower-test assertion line in actual tool output. Inspection of every matching call confirmed source reads through `cat`, directly or through `find`. All 240 author tool calls had captured outputs. Package metadata, file listings, and self-reports did not earn reading credit. No author tool command ran unit tests. This external analysis does not add a transcript parser to this package.

One blinded `gpt-6-luna@xhigh` reviewer assessed the forty pilot packets and 27 calibration packets in one mixed batch. It attributed all forty pilot failures to the intended defect. All four known positive controls earned credit and all 23 negative controls earned none. This small calibration set does not establish general reviewer accuracy. A primary AI inspection of every submitted file and changed-run assertion error agreed with those attributions.

## Human attribution remains pending

The AI decisions were not imported as human judgments. The official evaluator still reports zero accepted human-reviewed detections and twenty review-pending sessions per arm. Its complete-pilot gate remains false. The provisional counts above must not be presented as completed human review.

The proposed promotion rule also requires more detections overall and gains in at least two scenarios, with no decline on stale or missing tests. The exploratory results show no gain overall or in any scenario. They do not support a production guidance change.

## Conditions and limits

The cohort ran on 2026-10-17 at source revision `0aeb613b6cabf30ea8fa40e04e68309a78bfe101`. Both arms used `gpt-6.1-sol@high`, the same task and public inputs, and the same limits of 32 completed model responses, 400,000 reported tokens, and 600 authoring seconds per session. Seed 42 scheduled twenty matched pairs, with ten baseline-first and ten treatment-first starts. Sessions ran sequentially in that frozen order. No author was retried, and no task, fixture, grading rule, or denominator changed after outcomes were observed.

An external Codex 0.159.2 launcher supplied fresh sessions and a sandboxed Darwin executor after native Chromium sandbox setup failed during preflight. Preflight and smoke sessions preceded the cohort and are not pilot attempts. The admitted boundary allowed project contents, named public runtime files, project writes, and loopback networking. The common bundled system-skill catalog was present in both arms. The boundary permitted public metadata and default process/Mach operations; it was an operational restriction, not an adversarial sandbox certification. Node was 24.19.0. The copied runner and web engine reported versions 0.21.2 and 0.15.2.

The baseline already reached the maximum possible detection count. These small applications and explicit requirements leave no room to demonstrate a gain on this metric. Five sessions per cell, one author model, and four designed regressions do not establish equivalence or generalization. The randomized treatment was the inspection instruction, not the existence of unit tests or an enforced inspection action. This result does not show that unit tests are useless.

Baseline consumption totaled 155 completed responses and 3,711,238 reported tokens. Treatment consumption totaled 125 responses and 2,901,310 reported tokens. Recorded authoring time totaled 1,047.68 and 728.33 seconds respectively. Token totals include cached and repeated input across responses. These are descriptive observations, not a cost estimate or a performance benchmark.

## Evidence and next decision

The contributor retains exact submissions, raw author transcripts, all forty grades, all 67 review packets, judgments, settings, protocol, and launcher receipts outside the repository. All packet evidence hashes and sealed input hashes were checked. An independent AI factual and documentation review using `gpt-6-astra@high` passed. That review does not satisfy the human attribution gate.

This document publishes aggregate observations. The private captures and external launcher are not included, so these aggregates alone are insufficient to independently reproduce or audit the live run. The existing experiment commands support a new externally launched cohort; they do not rerun this historical capture.

Keep this PR focused on evaluation. A follow-up should predeclare realistic cases where choosing useful UI checks is less explicit, while current product requirements remain authoritative. Preserve stale and unrelated-test controls. Draft and review that study separately before starting another cohort; do not retrofit its scenarios or thresholds onto this pilot.
